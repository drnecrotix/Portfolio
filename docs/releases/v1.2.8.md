# v1.2.8

Fixes production A/B telemetry behind reverse proxies and the Hero CTA layout regression introduced by variant B.

## Experiments

- Uses proxy-aware `x-forwarded-host` / `host` validation for experiment event submissions.
- Prevents false `403 Forbidden` responses on N0C/Passenger deployments.
- Keeps same-origin protection for public experiment telemetry.

## Homepage

- Changes the Hero micro-navigation wrapper from `motion.div` to semantic `motion.nav`.
- Prevents the Home hero direct-child height rule from stretching the CTA into a full-height vertical pill.
- Preserves the existing CTA visual style and protected Hero design.

## Release

- Version `1.2.8`.

- No new dependencies.
