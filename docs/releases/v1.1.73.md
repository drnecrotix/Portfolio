# v1.1.73 - In-App Browser Loader Compatibility

## First-visit loader

- Reworks the `Niko` first-visit loader for Facebook Browser, Instagram Browser and other embedded WebViews.
- Replaces the critical `clip-path` text reveal with transform, opacity and scale animation for more reliable compositor support.
- Adds a dedicated cinematic dark background with subtle animated cyan and violet motion layers instead of relying only on the normal site background.
- Keeps the existing signature-style `Niko` greeting and upward page reveal.
- Uses a deterministic timer for the loader exit instead of relying on an animation completion callback that embedded browsers may skip.
- Keeps the exit sequence stable across React rerenders by storing completion callbacks in refs.

## Storage resilience

- Guards homepage `sessionStorage` reads and writes so restricted embedded-browser storage cannot break the loader lifecycle.
- The page still opens and completes the reveal normally when session storage is unavailable.

## Included Experience changes

- Includes the compact Education / Journey / Experience selector and Partners & Sponsors showcase prepared in the same release branch.
- Keeps the restored Journey timeline and Experience CMS settings intact.

## Updater readiness

- Bumps Portfolio from `1.1.72` to `1.1.73` in the release branch.
- Admin Dashboard updater will detect `1.1.73` after the PR is merged into `main`.
- No Prisma migration is required.
- No dependency changes are required.
