# Portfolio v1.2.26

## Editorial Blog archive

- Rebuilds `/blog` as an editorial journal instead of relying only on the animated visual archive.
- Adds a journal introduction with publication and format counts.
- Adds publication-type navigation for Article, Thought, Note, Poetry, Project Log and custom type labels already configured in the CMS.
- Adds separate category and tag filters so type, category and tag no longer compete as the same taxonomy concept.
- Keeps the existing search flow and expands matching across titles, excerpts, categories, types and tags.
- Adds a visible `Clear filters` action whenever any archive filter is active.
- Adds latest/oldest sorting and persists the existing animated FlowingMenu as an optional Visual archive mode.
- Uses Editorial list mode by default for stronger readability and content discovery.
- Adds a Latest publication spotlight when browsing the unfiltered first page.
- Adds compact publication rows with image, type, category, title, excerpt, date, reading time and up to two visible tags.
- Keeps pagination bounded to nine publications per page.

## Archive performance

- Adds a dedicated lightweight `BlogArchivePost` payload.
- Stops sending complete sanitized article bodies to the browser just to render `/blog`.
- Computes reading time server-side while mapping the archive payload.
- Keeps the complete article content available only on individual publication routes.

## Publication reading experience

- Adds estimated reading time beside the publication date.
- Adds a thin reading-progress indicator for rich-text publications.
- Generates an `On this page` table of contents when an article or project log has at least three H2/H3 sections.
- Uses a sticky desktop TOC and a collapsible mobile TOC.
- Generates stable heading anchors so individual sections can be linked directly.
- Adds one-click Copy controls to code blocks rendered inside publications.
- Adds accessible image-preview behavior for supported inline article images.
- Makes the featured image open in a full-screen preview.
- Upgrades Share to use the native Web Share API when available with clipboard fallback.
- Keeps likes, views, language switching and comments intact.

## Publication-type presentation

- Keeps Poetry in its existing text-first serif presentation.
- Gives Note and Thought a narrower, quieter reading column without forcing a large featured-image treatment.
- Keeps Article and Project Log optimized for longer structured content and automatic TOC generation.

## Taxonomy and discovery

- Publication tags now link to the explicit `tag` filter instead of behaving as a generic text-search query.
- Direct archive URLs can initialize `q`, `type`, `category` and `tag` filters.
- Related publication cards are more visual while preserving the current server-side related-post source.

## Compatibility

- No Prisma migration is required.
- Existing Post records, post types, categories, tags, translations, comments, likes and view counters remain compatible.
- Existing Tiptap HTML and Poetry content require no migration.
- Existing FlowingMenu remains available as the optional Visual archive view.
