# Portfolio v1.1.50

## Homepage Blog and Projects list redesign

This update refines the homepage content sections introduced in v1.1.46.

### Blog
- Replaces the homepage Blog card grid with a compact vertical publication list.
- Keeps a small featured-image preview on desktop instead of large cards.
- Shows category, publication date, title and a short excerpt in each row.
- Uses a smaller section header so Blog content starts sooner on screen.

### Projects
- Aligns the homepage Projects list with the visual language of `/projects`.
- Uses smaller row sizing, typography and status badges than the full Projects archive.
- Shows a compact project image/banner when one is available.
- Keeps project category, description, tech stack and status visible without oversized titles.
- Removes the previous large `Selected projects` style heading.

### Scrolling
- Keeps the existing smooth Homepage flow: Hero -> Blog -> Projects.
- If Blog is hidden, Hero still moves directly to Projects.

### Upgrade notes
- No Prisma migration is required.
- Homepage visibility and item-count settings are unchanged.
- Version bumped to `1.1.50` for Admin Dashboard update detection.
