# Portfolio v1.2.34

## Blog archive and footer

- Keeps the compact Blog footer in normal document flow so it no longer overlays the final FlowingMenu rows.
- Reworks the Blog tag rail into compact pill controls with previous/next arrows, mouse drag, native touch swipe and trackpad scrolling.
- Hides the native horizontal scrollbar in Chrome, Safari and Firefox while retaining accessible horizontal navigation.
- Replaces the first-load `scrollIntoView` behavior with rail-local positioning so opening `/blog` does not produce a page jump.

## Journal appearance CMS

- Adds `Journal appearance` under Blog administration.
- Makes the public eyebrow, title and subtitle editable without changing publication content.
- Adds selectable title effects: None, Fade, Slide, Gradient and Glitch.
- Adds an optional rotating-word / rotating-phrase title mode with editable prefix, suffix, up to eight phrases and configurable interval.
- Includes a live preview inside the Blog appearance editor.
- Stores Blog appearance settings inside the existing SiteSettings JSON envelope without changing Post records or requiring a Prisma migration.

## Mobile publication regression

- Fixes archive-only mobile CSS leaking into individual publications because both archive and article tag areas used the same `Publication tags` aria label.
- Scopes archive layout rules specifically to the archive tag `div`, while individual publication tag sections remain untouched.
- Restores a clean mobile pre-image hierarchy for Back to journal, publication taxonomy, title, excerpt and author/date/reading-time metadata.
- Keeps the featured image separated from the publication header with mobile-safe spacing.

## Compatibility

- No Prisma migration.
- No Post schema change.
- Existing Blog posts, translations, likes, views, reading progress, comments and related-publication behavior remain compatible.
