# Portfolio v1.2.38

## Homepage profile card identity

- Adds an independent `Profile card name` setting to Homepage administration.
- The profile card no longer has to mirror the global site name.
- Leaving the profile name empty keeps the existing fallback to the public site identity.
- Profile title, description, image and social links keep their current behavior.
- The setting is stored inside the existing homepage content JSON, so no Prisma migration is required.

## Compatibility

- No database migration.
- Existing homepage content remains valid through normalization defaults.
- Existing sites continue showing the site name until a custom profile name is saved.
