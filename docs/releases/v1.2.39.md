# Portfolio v1.2.39

## Blog image protection

- Extends watermark coverage from only the first Blog image to the featured image and inline article images.
- Keeps watermarking active for inline article images even when a publication has no featured image.
- Prevents protected Blog images from opening the existing featured-image or article-image lightboxes, so the watermark remains on the visible image surface.
- Blocks normal click, auxiliary-click, context-menu, drag and Enter/Space activation paths on protected Blog image hosts.
- Marks protected images as non-draggable and disables selection/drag cursor behavior.
- Keeps related-publication thumbnails interactive by excluding Blog navigation links from the protected-image scope.

## Notes

- Aligns NOTE publication headers with the regular Article heading hierarchy and centers the Journal/type/category line, title, excerpt and publication meta for a more deliberate note-style masthead.
- Removes the Featured image picker for NOTE entries and clears legacy NOTE featured images when content is normalized or saved.
- Keeps NOTE pages text-first while using a dedicated system Note cover in Blog archive previews and social sharing metadata.
- The system Note cover is not rendered as a large image inside the NOTE publication itself.

## Gallery media viewer

- Fixes Gallery detail images that could fail with HTTP 400 when CMS media lived on an R2 or other custom public media domain not listed in Next Image remote patterns.
- The zoom viewer now renders already validated Gallery media URLs directly instead of routing them through `/_next/image`.
- Preserves zoom, pan, rotate, watermark and image-series thumbnail behavior.
- Does not broaden Next.js remote image permissions with a wildcard host rule.

## Compatibility

- No Prisma migration.
- No Post schema changes.
- Existing watermark and Gallery configuration remain compatible.
- Browser-side image protection remains a deterrent and does not make public image URLs inaccessible to developer tools or network inspection.
