# Portfolio v1.2.53

## Holehe sidecar for email → related accounts

- Add `docker/holehe` FastAPI service wrapping the Holehe OSINT modules (120+ registration checks)
- Document setup in `docs/holehe.md`
- Digital Footprint already calls `HOLEHE_API_URL` + `HOLEHE_API_TOKEN`; this release ships the runnable sidecar
- Longer timeout for the Holehe provider path so slow multi-site sweeps can finish

### Enable

```bash
export HOLEHE_API_TOKEN="$(openssl rand -hex 24)"
docker compose -f docker/holehe/docker-compose.yml up -d --build
# App env:
# HOLEHE_API_URL=http://127.0.0.1:8787
# HOLEHE_API_TOKEN=<same>
```
