# Portfolio v1.2.50

## Digital Footprint enrichment and admin bot-check control

- Shows full structured exposed data (bio, location, followers, public email and other public profile fields) in finding details.
- Adds a related-accounts list for public profiles linked to the searched email, phone or username.
- Expands username coverage with Docker Hub and Bitbucket, and extracts richer public fields from existing platforms.
- Enriches Gravatar, GitHub and GitLab email matches with structured exposed field maps.
- Adds an admin Tools page for Digital Footprint with a toggle to require or disable the public bot check (`footprint.botCheckEnabled`).
- When bot check is disabled in admin, the public form hides the challenge and the scan API skips verification.
