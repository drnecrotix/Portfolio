# v1.2.9

Adds privacy-minimised traffic analytics, improves A/B experiment consistency and clarity, simplifies the Admin Dashboard, and includes several small public UI fixes.

## Analytics and A/B experiments

- Keeps homepage A/B variants stable for the current browser session instead of re-randomising on every refresh.
- Uses a small first-party session cookie containing only the assigned A/B variant letters.
- Adds short-retention traffic analytics for country and broad device class only.
- Does not store city, precise coordinates or raw IP addresses in the analytics database.
- Uses a random HTTP-only traffic session cookie whose value is hashed before the temporary server-side session record is stored.
- Keeps anonymous traffic-session records for about 24 hours of inactivity and country/device aggregates for about 31 days.
- Honors the browser Do Not Track signal for public page-view analytics.
- Adds 24h, 7 day and 30 day traffic views where relevant.
- Broadens supported country headers so country attribution works with more reverse-proxy and edge configurations.

## Experiments dashboard

- Separates A/B tests and Audience analytics into clear tabs so the page is easier to scan.
- Simplifies experiment cards around the primary conversion, current leader, lift and sample size.
- Moves sample warnings and supporting event counters into expandable details instead of showing everything at once.
- Adds a clearer country-level audience map, selected-country summary and clickable country ranking.
- Makes missing country attribution explicit when the hosting proxy does not forward a supported country header.
- Keeps analytics at country level only - no city-level view is collected or displayed.

## Admin Dashboard

- Replaces the generic timeline with an interactive weekday traffic chart for Monday through Sunday.
- The weekday view supports 7-day and 30-day comparisons and exposes average views, visits, pages per visit and the peak weekday.
- Removes the standalone statistics strip at the top of Dashboard.
- Moves Projects, Posts, Pages, Media and Draft posts into a compact Content snapshot inside Site Health.
- Removes the standalone AI Assistant card from Dashboard while keeping Assistant access available through Quick Access.
- Reduces the Public cache card to a single `Purge public cache` action inside Site Health.
- Removes the large Recent revisions list and keeps Revision history available through Quick Access.

## Gallery and watermark

- Applies the shared Content Watermark to public `/gallery` listing images and tag-filtered Gallery listings.
- Keeps the existing per-work Gallery viewer copyright watermark.
- Updates the Content Watermark admin description to reflect Gallery coverage.

## Wiki mobile

- Makes the mobile Wiki `Contents` control more visible and touch-friendly.
- Keeps the desktop Wiki sidebar layout unchanged.

## Projects

- Removes the misleading zoom cursor and click-to-zoom behaviour from the main Project hero image.
- Keeps the real Visual Gallery image viewer interactive.

## Privacy and release

- Updates Privacy & GDPR and Cookie Policy content for session-stable A/B assignment and short-retention traffic analytics.
- Adds Prisma migration `20260904095500_traffic_analytics`.
- Version `1.2.9`.
- No new runtime dependencies.
