# Portfolio v1.2.30

## Reading progress placement

- Moves the publication reading-progress rail from the top of the viewport to a floating position near the bottom edge.
- Keeps the indicator above the mobile safe-area so it does not collide with browser chrome or gesture areas.
- Shows the progress rail only while the article body is in the active reading zone.
- Fades and slides the rail out after the visitor scrolls past the end of the post, so it does not remain visible over comments or related publications.
- Keeps the existing document-level portal and 0-100% progress semantics from v1.2.29.

## Admin analytics usability

- Extracts the proven mouse-wheel containment behavior from the desktop admin sidebar into one shared helper.
- Reuses the same contained scrolling in long Analytics lists, including live pages, countries, cities and Recent page activity.
- Uses the same thin scrollbar treatment for those bounded data areas so long lists remain compact without making the surrounding dashboard excessively tall.
- Adds an OS column to Recent page activity with coarse labels such as Windows, macOS, iOS/iPadOS, Android, ChromeOS and Linux.
- OS is derived from the browser user-agent at request time, while the full user-agent string is not retained.
- Keeps older page-activity rows compatible by reporting their OS as Unknown.

## Compatibility

- No Prisma migration.
- No Post schema changes.
- No changes to quote styling or the Blog archive layout.
- Existing traffic metric and page-activity data remain readable.
