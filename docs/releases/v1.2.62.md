# Portfolio v1.2.62

## Service estimate regression coverage

- Adds focused unit regression tests for the contextual service-estimate model introduced in v1.2.61.
- Verifies that FAIL findings remain more expensive than equivalent WARN findings.
- Verifies simple, complex and specialist remediation classes preserve their expected ordering.
- Verifies bounded affected-item volume increases remediation estimates without unbounded growth.
- Verifies CMS/technology and access availability refine web-service estimates.
- Verifies email-domain estimates remain independent from CMS and access modifiers.
- Verifies bundle adjustments stay at the intended thresholds.
- Adds a Playwright regression scenario for the real service-request form using a deterministic mocked Website Inspector response.
- Verifies customer-entered budget does not alter the automated estimate shown in the UI.
- Runs the new unit regression suite in Portfolio CI before builds.

This release adds test coverage and CI protection only. It does not change the service-estimate pricing model or the Web Health Suite design.
