# Portfolio v1.1.46

Homepage content expansion update.

## Homepage Blog

- Adds a latest Blog publications section below the hero.
- Shows featured image, category, publication date, title and excerpt.
- Adds a direct link to the full Blog archive.
- Homepage Admin can enable or hide the section.
- Homepage Admin can edit the section title/subtitle and choose how many posts are shown (1-12).

## Homepage Projects

- Adds a Projects section below Blog using a compact list-style layout.
- Shows project title, short description, category and status.
- Adds a direct link to the full Projects archive.
- Homepage Admin can enable or hide the section independently of Blog.
- Homepage Admin can edit the section title/subtitle and choose how many projects are shown (1-12).

## Smooth section navigation

- Scrolling down from the homepage hero smoothly moves to Blog when Blog is enabled.
- If Blog is hidden, the hero moves directly to Projects when Projects is enabled.
- When the user reaches the end of Blog and continues scrolling down, the page smoothly transitions to Projects.
- Normal scrolling remains available inside longer sections so content is not skipped.

## Upgrade

- Version bumped from 1.1.45 to 1.1.46 for Admin Dashboard update detection.
- No Prisma schema migration is required. Homepage options remain stored in the existing JSON settings field and are backward compatible.
