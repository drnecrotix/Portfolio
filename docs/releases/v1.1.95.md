# v1.1.95 - Gallery viewer and engagement

## Viewer controls

- Removes mouse-wheel / trackpad zoom from `/gallery/[slug]` so normal page scrolling is never intercepted by the image viewer.
- Keeps explicit zoom controls, double-click zoom/reset and keyboard `+` / `-` controls.
- Changes the circular-arrow control from a misleading reset action into a real 90-degree image rotation control.
- Clicking the zoom percentage resets zoom and pan position.
- `Escape` resets zoom, pan and rotation.
- Updates the viewer hint to describe the remaining zoom controls accurately.

## Likes, views and sharing

- Adds a compact Like / Views / Share action row to Gallery work pages.
- Views follow the Blog article pattern and are recorded once per browser session for each Gallery slug.
- Likes use a long-lived anonymous visitor cookie and can be toggled on/off.
- Native Web Share is used when supported, with clipboard fallback on desktop browsers.
- Adds dedicated PostgreSQL-backed Gallery engagement models instead of storing counters in the Gallery settings JSON.

## Social preview / OG image

- Gallery detail pages continue to emit server-rendered OpenGraph and Twitter metadata.
- An explicitly configured Gallery Social/OpenGraph image has priority.
- Image works fall back to their cover image when no dedicated social image is configured.
- Video works fall back to their configured thumbnail.
- Relative media URLs are converted to absolute public URLs before being emitted as social preview images.

## Release

- Version: `1.1.95`.
- Adds one Prisma migration for Gallery likes/views.
- No dependency changes.
- Homepage slider, Blog/Articles, Projects and Wiki layouts are unchanged.
