# Portfolio v1.1.74

## Editable Experience content

This release turns the `/experience` page from a mostly static presentation into a fully editable CMS section.

### Admin Experience editor
- Splits `/admin/experience` into General, Education, Journey, Experience and Partners & Sponsors tabs.
- Keeps all settings in one save flow while removing the previous long single-page editor layout.
- Adds animated tab transitions and an animated sticky save state.
- Saves with AJAX/server actions without reloading the admin page.
- Adds Saving, Saved and Error feedback plus a dismissible animated notification.
- Reuses the existing local draft protection and unsaved-changes warning behavior.

### Education
- Education records are now editable from the admin panel.
- Supports institution, degree, major, dates, ongoing status, GPA, activities and achievements.
- Records can be added and removed without editing source files.

### Journey
- Journey timeline records are now independently editable.
- Supports company, position, role type, dates, location, logo, links, description, skills, responsibilities, impact and key learnings.
- The original visual Journey timeline remains intact while reading CMS data.

### Experience archive
- Experience archive records are now independently editable from Journey.
- Existing category prefixes continue to control which archive category contains each record.
- Category labels, descriptions and prefixes remain editable.

### Partners & Sponsors
- Partner and sponsor logos are now editable in the Experience admin panel.
- Logos can be enabled, disabled, added, removed and linked to partner websites.
- New or replaced partner images must use `.svg` files.
- Existing legacy WebP logos remain supported until they are replaced, preventing a destructive migration.

### Compatibility
- Existing `portfolioData` content is used as the initial fallback when no CMS dataset has been saved yet.
- No Prisma migration is required.
- No dependency changes are required.
- Compatible with the existing Admin Dashboard updater and N0C deployment flow.
