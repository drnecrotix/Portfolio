# Portfolio v1.1.47

## Navigation editor refresh

This release redesigns `/admin/navigation` to make menu management faster and reduce full-page reloads.

### Changes

- Replaces the expanded menu cards with a compact list that shows the menu name and current position.
- Adds native drag-and-drop ordering for top-level menus and submenu items.
- Drag-and-drop order changes are saved immediately through server actions without a page reload.
- Adds an `Edit` control that expands the full settings only for the selected menu item.
- Replaces the per-menu Save buttons with one global `Save changes` action.
- Saves all edited menu settings in one validated server-side transaction.
- Adds AJAX/server-action create and delete flows without navigating away from the editor.
- Keeps top-level and submenu ordering independent and prevents invalid cross-level drag operations.
- Preserves dropdown, visibility, external-link and parent validation.
- Keeps public navigation revalidation after successful changes.

### Upgrade notes

- No Prisma migration is required.
- Existing navigation records are preserved.
- Package version is bumped from `1.1.46` to `1.1.47` for Admin Dashboard update detection.
