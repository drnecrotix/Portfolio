# v1.2.14

Adds Creem as an optional payment provider for the Necrotix Lab Digital Store while keeping Lemon Squeezy available for existing products.

## Store payment providers

- Adds per-product payment provider selection: `Creem` or `Lemon Squeezy`.
- Existing Store products remain on Lemon Squeezy after the migration.
- New products created from Admin default to Creem in the product form.
- Creem products use a `prod_...` Product ID instead of a Lemon Squeezy Variant ID.
- Publishing still requires a private digital file and the identifier for the selected provider.

## Creem checkout

- Adds server-side Creem checkout creation through `POST /v1/checkouts`.
- Automatically routes `creem_test_` API keys to `https://test-api.creem.io`.
- Live Creem keys use `https://api.creem.io`.
- Sends the internal Store product ID and checkout-session token as Creem metadata.
- The success redirect does not grant access by itself.

## Creem webhooks

Adds:

`/api/store/webhook/creem`

The endpoint:

- verifies the `creem-signature` HMAC-SHA256 signature against the raw request body
- grants Store downloads only after `checkout.completed`
- matches the signed Creem event to the internal checkout session and Store product
- processes webhook retries idempotently through the existing order/grant upserts
- revokes Store downloads after `refund.created`
- revokes Store downloads after `dispute.created`

## Admin > API Integrations

Adds a Creem card with encrypted CMS fields for:

- API Key
- Webhook Secret

Environment fallbacks:

- `CREEM_API_KEY`
- `CREEM_WEBHOOK_SECRET`

The Test connection action uses the API-key prefix to choose the correct Creem environment and checks the Products API.

## CLI setup

The official Creem CLI can be installed for local development with:

```bash
npm install -g @creem_io/cli
creem login
creem whoami
```

Keep API keys outside Git and enter them interactively, through environment variables, or through the encrypted CMS integration vault.

## Configuration after deploy

1. Open Admin > API Integrations > Creem.
2. Enter the Creem test API key and save it.
3. Create a Test Mode webhook in Creem and point it to `https://necrotixlab.com/api/store/webhook/creem`.
4. Subscribe to `checkout.completed`, `refund.created`, and `dispute.created`.
5. Copy the webhook signing secret into Admin > API Integrations > Creem.
6. Create a one-time Creem product and copy its `prod_...` Product ID.
7. In Admin > Digital Store select `Creem` as payment provider and paste that Product ID.
8. Upload the private digital file and publish the Store product.
9. Run a test purchase before switching to live credentials.
