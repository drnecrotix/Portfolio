# Portfolio v1.2.23

## Analytics dashboard refinement

- Refines the traffic dashboard around patterns used by established analytics products such as Plausible, Umami and PostHog: live status first, compact metric cards, bounded detail lists and focused location views.
- Keeps the four practical summary metrics: visitors online, pages active now, visits and countries.
- Places `Pages being viewed` and `Daily visits` side by side on wide screens to use dashboard space more efficiently.
- Gives live-page and location lists their own bounded vertical scrolling so large traffic volumes do not stretch or break surrounding cards.
- Removes the duplicate `Visitors online by country` block.
- Replaces separate location blocks with one `Audience locations` panel using `Countries` and `Cities` tabs.
- The Countries tab shows exact visit totals for the selected period plus visitors online now.
- The Cities tab is live-only and appears when the hosting/CDN already supplies a coarse city header. No external IP-to-city lookup or precise-coordinate collection is added.
- Makes the world map more compact and shades country activity by visits rather than raw page opens.
- Simplifies device analytics into compact visit counts with relative bars.
- Counts a new analytics visit after about 30 minutes of inactivity while keeping heartbeat requests from inflating page-view totals.

## Gallery tag navigation

- Fixes URL-encoded Gallery tags such as `black&white` so filtered routes resolve the same tag stored on Gallery works.
- Normalizes tag matching for URL encoding, Unicode, case and repeated whitespace.
- Adds a visible `Clear filter` control to tag-filtered Gallery views that returns to `/gallery` and restores all works.

## Admin navigation

- Makes the expanded desktop admin sidebar independently scrollable with the mouse wheel when its content is taller than the viewport.
- Keeps the sidebar viewport-bound and uses a compact visible scrollbar so expanded groups remain accessible without scrolling the main admin content.

## Privacy and retention

- Updates the Privacy & GDPR and Cookie policies for current-path reporting, optional infrastructure-provided live city labels and the 30-minute visit inactivity window.
- City labels remain only in short-lived traffic-session rows and are not copied into longer-lived country/device aggregate metrics.
- Raw IP fallback remains limited to country resolution and short retention.

## Database

- Adds nullable `TrafficSession.currentCity` for optional short-lived city context supplied by the hosting/CDN.
- Adds migration `20260906113000_live_traffic_city`.
- Leaves the already released v1.2.22 traffic migration unchanged.
- Existing country/device aggregate traffic data remains compatible and requires no historical rewrite.
