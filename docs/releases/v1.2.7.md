# Portfolio v1.2.7

Privacy-friendly A/B testing for the NecrotixLab homepage.

## Experiments

Three independent 50/50 experiments now run on each homepage request:

- **Niko intro duration**
  - A: current 2.5 second first-visit intro
  - B: faster 1.8 second first-visit intro
  - Primary metric: engaged first visit
- **Homepage section order**
  - A: Journal before Projects
  - B: Projects before Journal
  - Primary metric: project open
- **Hero micro navigation**
  - A: current hero without text CTA
  - B: discreet `View projects` and `Explore gallery` links
  - Primary metric: project open

The protected `HeroVisual` component is not redesigned. Variant B adds a lightweight overlay from `HomeClient`.

## Privacy model

- Variants are assigned server-side for each dynamic homepage request.
- A/B testing creates no experiment cookie, localStorage entry or sessionStorage entry.
- Event de-duplication exists only in component memory for the current page view.
- The server stores aggregate counters only.
- No experiment visitor ID, name, email address or IP address is stored in the experiment table.
- Same-origin validation is applied to the public event endpoint.
- Privacy and Cookie policies document the aggregate experiment measurement.

This intentionally treats the unit of analysis as a homepage visit instead of building a persistent visitor profile.

## Admin

Adds **Admin > Tools > Experiments** for OWNER and ADMIN roles.

The dashboard:

- refreshes automatically every 5 seconds;
- shows A/B exposures and primary conversion rates;
- calculates B vs A lift;
- shows supporting engagement events;
- avoids declaring a winner when the sample is too small.

## Niko timing

`LoadingScreen` now supports a genuinely shorter timing path while preserving the existing visual treatment. The current 2.5 second variant retains its existing 1.4 second dissolve; the faster variant uses a shorter dissolve so its requested duration is actually achieved rather than being clamped back toward the current timing.
