# v1.2.9

Adds privacy-minimised traffic analytics, improves A/B experiment consistency and clarity, expands the Admin Dashboard, and includes several small public UI fixes.

## Analytics and A/B experiments

- Keeps homepage A/B variants stable for the current browser session instead of re-randomising on every refresh.
- Uses a small first-party session cookie containing only the assigned A/B variant letters.
- Adds short-retention traffic analytics for country and broad device class only.
- Does not store city, precise coordinates or raw IP addresses in the analytics database.
- Uses a random HTTP-only traffic session cookie whose value is hashed before the temporary server-side session record is stored.
- Keeps anonymous traffic-session records for about 24 hours of inactivity and country/device aggregates for about 31 days.
- Honors the browser Do Not Track signal for public page-view analytics.
- Adds 24h, 7 day and 30 day traffic views.

## Experiments dashboard

- Redesigns experiment cards with clearer A/B comparison and primary conversion metrics.
- Adds sample balance, sample status and easier-to-read B vs A lift information.
- Adds live traffic summary, country-level audience map and device breakdown.
- Keeps analytics at country level only - no city-level view is collected or displayed.

## Admin Dashboard

- Adds a traffic graph with 24h / 7 days / 30 days range switching.
- Adds current visits, page views, country and device summaries.
- Adds Site Health information.
- Removes the large Recent revisions list.
- Keeps Revision history available through Quick Access.

## Gallery and watermark

- Applies the shared Content Watermark to public `/gallery` listing images and tag-filtered Gallery listings.
- Keeps the existing per-work Gallery viewer copyright watermark.
- Updates the Content Watermark admin description to reflect Gallery coverage.

## Wiki mobile

- Makes the mobile Wiki `Contents` control more visible and touch-friendly.
- Keeps the desktop Wiki sidebar layout unchanged.

## Projects

- Removes the misleading zoom cursor and click-to-zoom behaviour from the main Project hero image.
- Keeps the real Visual Gallery image viewer interactive.

## Privacy and release

- Updates Privacy & GDPR and Cookie Policy content for session-stable A/B assignment and short-retention traffic analytics.
- Adds Prisma migration `20260904095500_traffic_analytics`.
- Version `1.2.9`.
- No new runtime dependencies.
