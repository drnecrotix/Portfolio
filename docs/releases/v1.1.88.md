# v1.1.88 - Wiki FAQ overlap fix

## FAQ layout fix

- Removes the sticky behavior from the public FAQ search/category toolbar so it can no longer cover FAQ questions while scrolling.
- Keeps search, result count and category filters in normal document flow on mobile and desktop.
- Hides the native horizontal scrollbar under category chips while preserving touch/mouse horizontal scrolling.
- Adds slightly clearer spacing between the filter controls and the FAQ list.

## Scope

- Public `/wiki/faq` only.
- No FAQ CMS/data model changes.
- No Prisma migration.
- No dependency changes.
- Version: `1.1.88`.
