# Portfolio v1.1.48

Contact form delivery controls and anti-bot hardening.

## Added

- Private Contact form recipient email setting in Admin Settings.
- Recipient address can differ from the public contact email.
- Delivery fallback order: form recipient -> public contact email -> `EMAIL_USER`.
- More Contact form reasons: project, development, creative, community, partnership, business, support, media, career, feedback and other.

## Improved

- Reason dropdown is readable in both Day and Night modes.
- Contact form uses a persistent in-process IP rate limiter.
- Same-origin validation blocks cross-site form submissions.
- JSON content-type validation rejects unsupported submission formats.
- Honeypot protection remains enabled.
- Minimum completion-time validation quietly drops obvious automated submissions.
- Contact API responses use `Cache-Control: no-store`.

## Compatibility

- No Prisma migration required.
- Existing public contact email remains unchanged.
- Existing contact forms continue to use SMTP credentials from the environment.
