# v1.3.10 - Service navigation refinement

- Changes the back action on Website Inspector, Website Project and Website Support to Services and routes it to `/services`.
- Keeps the Services landing page's Back to Lab action unchanged and linked to `/lab`.
- Reduces request amplification by prioritizing the active origin for site-mode checks, coalescing concurrent checks and briefly caching the result.
- Shortens failed internal site-mode probes so an unreachable configured origin cannot stall every public page request.
