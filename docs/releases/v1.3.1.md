# Portfolio v1.3.1

## Service Request admin navigation

- Adds an explicit `Back to service requests` action inside every expanded Service Request in Admin.
- Returning to `/admin/service-requests#service-request-list` reloads the list with request details collapsed and scrolls back to the request list.
- Adds a stable `service-request-list` anchor to make the return action predictable on desktop and mobile.
- No Service Request data model, pricing, email delivery or lifecycle behavior is changed.
