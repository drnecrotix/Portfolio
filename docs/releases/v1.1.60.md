# Portfolio v1.1.60

## Comments list polish

- Gives each root blog comment a lightweight visual container instead of leaving comments as loose text.
- Improves author/date hierarchy and spacing inside each comment.
- Keeps replies visually lighter and nested with a subtle vertical guide.
- Refines the Reply action so it reads as a secondary interaction without becoming a heavy button.

## Advanced SEO and indexing

- Expands Admin > SEO with global indexing controls for index/follow, archive, snippets, image indexing and translation directives.
- Adds Google preview controls for max snippet length, max image preview and max video preview.
- Adds optional canonical URL and configurable referrer policy.
- Adds Publisher and Application identity metadata.
- Extends Custom Meta Tags to support `name:`, `property:` and `http-equiv:` entries.
- Adds independent sitemap inclusion controls for Blog, Projects and CMS Pages while preserving automatic sitemap updates.
- Applies the advanced metadata settings to the public root metadata and keeps safe defaults for existing installations.
- Preserves existing social image, Open Graph, Twitter/X, RSS and Google verification settings.
- No Prisma migration required because SEO settings remain JSON-backed.
