# Portfolio v1.2.36

## Creative dropdown refresh

- Refines the v1.2.35 dropdown variants with a more expressive NecrotixLab visual language while preserving the existing Admin variant selector.
- Uses inspiration from motion-focused open-source UI projects such as Motion Primitives, Magic UI and React Bits without copying their components or source code.
- Keeps the Radix Popover accessibility, portal rendering, collision handling and keyboard navigation introduced in v1.2.35.

## Minimal

- Reworks the compact variant into a cleaner editorial index.
- Uses animated row surfaces, circular numbering, directional motion and a restrained active-state treatment.
- Removes the secondary raw URL/path line entirely.

## Glass

- Adds layered depth, ghost numbering, directional motion, subtle glow and stronger hover transitions.
- Keeps link names as the primary information instead of showing technical URL paths.
- External links may show a small `external` context label instead of their raw address.

## Mega cards

- Moves toward a bento/editorial presentation with larger ghost numbers, decorative lines, glow depth and floating directional controls.
- Keeps the two-column layout for larger menu groups while making each destination more visually distinctive.
- Removes the raw `/page-name` text from cards.

## Compatibility

- No Prisma migration.
- No navigation schema changes.
- Existing Auto / Minimal / Glass / Mega cards settings remain compatible.
- Mobile fullscreen navigation is unchanged.
