# v1.1.89 - Career Dossier

## Resume redesign

- Replaces the full-screen PDF-only `/resume` experience with a portfolio-native Career Dossier.
- Keeps the traditional PDF available through dedicated Open PDF and Download CV actions.
- Removes the old Google Drive preview dependency from the public Resume page.

## Live CMS data

- The dossier reads the existing Journey CMS configuration instead of maintaining a second hardcoded work history.
- Respects Journey hidden/archive state before rendering education and work records.
- Uses the Personal Wiki profile title, portrait, aliases and subtitle when available.
- Uses public Site Settings identity/social links for GitHub, LinkedIn and Instagram.
- Revalidates every 60 seconds so published Journey changes can flow into the dossier.

## Career Dossier sections

- Profile hero with portrait, professional headline and Wiki aliases.
- Live signal counters for public roles, education records, capabilities and ongoing roles.
- Selected Experience sourced from Journey.
- Education overview sourced from Journey.
- Capability Index aggregated from skills attached to public roles, using evidence counts instead of proficiency percentages.
- Current Signal panel for ongoing roles.
- Fast links to Journey, Projects, Personal Wiki and The Lab.
- Traditional CV document card with open/download actions.

## SEO

- Adds a canonical `/resume` metadata definition with index/follow enabled.
- Adds ProfilePage + Person JSON-LD using the public identity and Wiki aliases.
- The route remains included in the existing sitemap.

## Release

- Version: `1.1.89`.
- No Prisma migration.
- No dependency changes.
- Existing updater and N0C compatibility behavior remain unchanged.
