# Portfolio v1.2.29

## Reading progress

- Reworks the publication reading-progress indicator so it is rendered through a document-level portal instead of inside animated article containers.
- Keeps the indicator fixed to the viewport beneath the main navigation while the publication is open.
- Uses a compact neutral progress rail with a percentage instead of the previous prominent colored bar.
- Keeps progress calculations tied to the article body and updates smoothly from 0 to 100 percent.
- Preserves progressbar accessibility semantics.

## Quote refinement

- Removes the colored accent rail and strong fuchsia/violet gradient from rich-text quotes.
- Replaces the previous high-contrast quote card with a quieter editorial surface using a neutral background, subtle border and soft depth.
- Keeps only a small low-contrast quotation mark as decoration.
- Preserves authored alignment, paragraph structure and inline formatting from the editor.

## Compatibility

- No Prisma migration.
- No Post schema changes.
- Existing publications and Tiptap content remain compatible.
