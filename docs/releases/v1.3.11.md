# v1.3.11

Technical quality release focused on restoring a clean lint baseline without changing public product behavior.

## Changes

- Cleans all existing ESLint errors and warnings across the application.
- Keeps runtime hook-order validation enabled while documenting compatibility exceptions for legacy visual components.
- Fixes conditional and callback-based hook usage in animation components.
- Improves the gallery admin tabs with complete tablist, tab and tabpanel semantics.
- Removes obsolete inline lint suppressions and applies safe const and text-escaping fixes.

- `npm run typecheck`
- `npm run test:unit` - 15 tests passed
- `npm run build`
