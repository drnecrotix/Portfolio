# Portfolio v1.2.21

## Store simplification

- Removes the large promotional hero from the public `/store` page.
- Removes the featured/latest product showcase above the catalog.
- Opens the Store directly with search, sorting and category filters.
- Keeps the page focused on browsing products without promotional clutter.
- Preserves an accessible hidden Store heading for page semantics and SEO.

## Compact catalog

- Makes product cards significantly more compact and suitable for denser browsing.
- Uses a shorter 4:3 product image instead of square artwork tiles.
- Increases catalog density up to six columns on very wide screens.
- Reduces card padding, grid gaps, badge size and visual chrome.
- Keeps category, title, price, a one-line description and file count in a condensed layout.
- Retains Featured and Free badges inside product cards where applicable.
- Keeps the compact responsive search and sort toolbar.
- Preserves desktop/mobile overflow protections and responsive behavior.

## Catalog loading and performance

- Limits the initial server query to the first 18 products instead of loading the complete Store catalog.
- Adds a paginated public Store products endpoint for subsequent catalog requests.
- Adds `Load more products` so additional items are fetched only when requested.
- Search, category filtering and sorting are performed server-side, including products that have not been loaded yet.
- Debounces text search to avoid unnecessary requests while typing.
- Uses native lazy image loading and async decoding for product covers.
- Uses `content-visibility` on product cards so off-screen catalog items require less rendering work.
- Keeps result counts and category totals without transferring every product to the browser.

## Security hardening

- Adds `Strict-Transport-Security: max-age=31536000` to application responses.
- Disables the default Next.js `X-Powered-By` response header.
- Publishes `/.well-known/security.txt` with the site contact, canonical URL, expiry and preferred languages.
- Keeps the existing CSP and cross-origin opener policy unchanged to avoid breaking supported external embeds.

## Compatibility

- No Prisma migration is required.
- No changes to checkout, cart, payment-provider, download-grant or Store storage behavior.
- Existing Store products require no data changes.
