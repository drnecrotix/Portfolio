# Portfolio v1.1.51

## Homepage landing-page scroll flow

This update fixes the homepage section stacking and turns the public homepage into a full-screen landing-page flow.

### Landing sections
- Hero now occupies one complete viewport and no longer reveals Blog content before the first scroll.
- Blog occupies its own full-screen section.
- Projects occupies its own full-screen section.
- Mouse-wheel navigation moves smoothly between Hero, Blog and Projects.
- Scrolling upward moves back to the previous section when one exists.
- Hidden Blog or Projects sections are skipped automatically.

### Blog and Projects
- Reduces the compact section title from the previous `text-sm` treatment to a smaller `text-xs` treatment in both sections.
- Further tightens row spacing, thumbnails and metadata so the lists fit the landing-page presentation more naturally.
- Preserves the list-based Blog layout and the `/projects`-inspired Projects styling introduced in v1.1.50.

### Upgrade notes
- No Prisma migration is required.
- Homepage visibility settings remain unchanged.
- Version is bumped to `1.1.51` so the Admin Dashboard updater can detect this release after merge to `main`.
