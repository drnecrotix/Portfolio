# Portfolio v1.1.55

## Editorial Blog Experience

This release gives individual Blog publications a more personal journal identity while preserving the existing `/blog` archive list.

### Public article view
- Reworks `/blog/[slug]` into a narrower editorial/journal composition.
- Reduces the dashboard-like metadata presentation to one quiet author/date/type line.
- Keeps the featured image important without letting it dominate the first screen.
- Moves likes and sharing into a compact journal action row.
- Adds more expressive body typography, pull quotes, dividers and first-paragraph rhythm.
- Presents tags as lightweight Tumblr-style hashtags.
- Adds a small author note at the end of the publication.
- Separates Comments from the article body so tags and the author note close the post naturally.
- Replaces large related-post cards with a quieter journal reading list.

### Blog writing experience
- Adds a dedicated `journal` visual mode to the shared rich-text editor without changing Project editor styling.
- Gives Blog editing a focused writing canvas instead of a form-first CMS feeling.
- Adds an editorial Divider action for visual pauses.
- Gives Quote blocks a stronger pull-quote treatment in the editor and public article.
- Keeps existing draft recovery, unsaved preview, media, taxonomy, SEO and publishing controls.

### Scope
- `/blog` list/archive design is intentionally unchanged.
- No Prisma migration is required.
