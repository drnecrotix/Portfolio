# v1.3.12

Smarter website project configuration and consistent navigation across the public website analysis tools.

## Changes

- Adds a Services button to Website Inspector, Site Crawl / Broken Links, Accessibility Check and SEO Intelligence.
- Separates new website projects from improvements to an existing website.
- Treats domain and hosting as independent choices and hides irrelevant checks or add-ons when either already exists.
- Recommends a website type, CMS or custom stack, functions and add-ons from the selected purpose.
- Supports business, portfolio, stores, publications, gaming communities, recipes, knowledge bases, courses, bookings, directories and custom platforms.
- Expands CMS choices to include WordPress, WooCommerce, Shopify, Ghost, Drupal, Joomla, Webflow, Framer, Discourse, Next.js, Strapi, Sanity, Directus and custom development.
- Adds CMS-aware improvement suggestions for existing websites.
- Extends live estimate pricing for specialized website types and functions.
