# v1.3.2

- Adds a dedicated DataForSEO card to Admin > API Integrations.
- Stores the DataForSEO API login and API password with the existing encrypted integration vault.
- Supports CMS credentials with `DATAFORSEO_LOGIN` / `DATAFORSEO_PASSWORD` environment fallback.
- Adds a free DataForSEO connection test using `GET /v3/appendix/user_data`, so credential verification does not consume paid SEO requests.
- Persists the latest DataForSEO connection-test result in integration metadata.
- Revalidates SEO Intelligence after credential changes so newly configured credentials are available without code changes.
- Keeps DataForSEO credentials server-side and never returns stored login/password values to the browser.
