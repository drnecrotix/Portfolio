# Portfolio v1.2.21

## Store simplification

- Removes the large promotional hero from the public `/store` page.
- Removes the featured/latest product showcase above the catalog.
- Opens the Store directly with search, sorting and category filters.
- Keeps the page focused on browsing products without promotional clutter.
- Preserves an accessible hidden Store heading for page semantics and SEO.

## Catalog refinements

- Keeps product counts in category filters.
- Uses a consistent product-card grid instead of a widened featured card.
- Retains Featured and Free badges inside product cards where applicable.
- Keeps the compact responsive search and sort toolbar.
- Preserves desktop/mobile overflow protections and responsive behavior.

## Compatibility

- No Prisma migration is required.
- No changes to checkout, cart, payment-provider, download-grant or Store storage behavior.
- Existing Store products require no data changes.
