# Portfolio v1.2.60

## Customer service cycle

- Adds a private customer-facing status page for each `KT-...` service request.
- Customer status access uses a server-generated HMAC token tied to the request reference and customer email; the public reference alone is not sufficient.
- Newly submitted requests return and email the private status link to the customer.
- Admin can send the final quote by email directly from Service Requests; successful delivery moves the request to `QUOTE_SENT`.
- Customers can review and accept an active final quote from the private status page, moving the request to `ACCEPTED`.
- Admin can run the original audit tool again and capture an `after` snapshot for before/after score comparison.
- Completed requests offer a weekly or monthly maintenance/monitoring request option; the preference is attached to the existing service request for follow-up.
- Private service pages are `noindex` and `no-store`.

## Web Health Suite

- Keeps the existing flat technical-report design and updates visible suite version labels to 1.2.60.
- Service request snapshots now retain enough audit context to support before/after verification while ordinary scans remain unstored.

## CSP / WebAssembly fix

- Fixes browser WebAssembly startup errors caused by competing global and `/lab` Content Security Policies.
- Keeps the default production CSP strict on non-Lab routes and gives `/lab` and its subpaths one dedicated CSP with the narrower CSP3 `wasm-unsafe-eval` capability.
- Separates shared security headers from the route-specific CSP so `/lab` does not inherit a second stricter `script-src` policy that would block Spline WebAssembly.
- JavaScript `unsafe-eval` remains disabled in production outside the existing development-only allowance.
- Grammarly console warnings remain browser-extension messages and are not application errors.

## Navigation fix

- External `http://` and `https://` menu URLs are now auto-detected server-side instead of being rejected as internal paths when the External flag is not already set.
- The navigation editor also auto-marks edited absolute HTTP(S) URLs as external and accepts external URLs when creating new items.
- External URLs still reject embedded credentials and non-HTTP(S) schemes.
