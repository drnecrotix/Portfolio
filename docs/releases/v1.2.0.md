# v1.2.0

Gallery Admin persistence and legacy asset cleanup.

## Gallery Admin

- Fixes a cross-tab save bug where saving from `Interface`, `Page` or another tab could submit only that mounted panel and overwrite missing Gallery fields.
- Keeps all top-level Gallery Admin panels mounted while switching tabs, so their form state remains part of the save operation.
- Adds a server-side safety layer that preserves the current database value when a Gallery field is not present in a submission.
- Prevents `galleryItems` from becoming an empty list just because `Works` was not the active tab during Save.
- Keeps the active top-level Gallery Admin tab after `Save Gallery`.
- Saving from `Page` returns to `Page`; saving from `Interface` returns to `Interface`; the same applies to `Works` and `Published`.
- Preserves the active tab when a save error is returned, so the edited panel remains visible.
- Existing Gallery values such as `Creative Types label` remain visible immediately after the save redirect.

## NSFW control

- Reworks the existing NSFW preview checkbox into a compact switch-style control.
- Adds clear `ON` / `OFF` state feedback.
- Removes the long helper paragraph from the visible control while keeping the existing NSFW behavior unchanged.
- Keeps keyboard focus visibility and native checked-state accessibility.

## Gallery content source

- Disables the old `public/gallery` filesystem fallback by default.
- An empty CMS Gallery now stays empty instead of automatically showing old template images.
- Removes the disabled Navigation Shortcuts implementation that still referenced legacy Gallery assets.
- Removes 15 obsolete images from `public/gallery` that belonged to the old template/fallback content.
- Does not remove or alter `public/uploads`, Media Library files, R2 media, or configured Gallery works.

## Release

- Version `1.2.0`.
- No Prisma migration.
- No new dependencies.
- Existing public Gallery visual layout is preserved.
