# v1.1.89 - Career Dossier

## Resume redesign

- Replaces the full-screen PDF-only `/resume` experience with a portfolio-native Career Dossier.
- Keeps a formal CV as a companion document instead of making the PDF the entire page.
- Removes the old Google Drive preview dependency from the public Resume page.
- Replaces the bundled `public/resume.pdf` with a new two-page formal CV aligned with the Career Dossier structure.

## Live CMS data

- The dossier reads the existing Journey CMS configuration instead of maintaining a second hardcoded work history.
- Respects Journey hidden/archive state before rendering education and work records.
- Uses the Personal Wiki profile title, portrait and aliases when available.
- Uses public Site Settings identity/social links for GitHub, LinkedIn and Instagram.
- Revalidates every 60 seconds so published Journey changes can flow into the dossier.

## Career Dossier sections

- Profile hero with portrait and professional headline.
- Live signal counters for public roles, education records, capabilities and ongoing roles.
- Selected Experience sourced from Journey.
- Education overview sourced from Journey.
- Capability Index aggregated from skills attached to public roles, using evidence counts instead of proficiency percentages.
- Current Signal panel for ongoing roles.
- Fast links to Journey, Projects, Personal Wiki and The Lab.
- Managed formal CV card with Web View and Download CV actions.

## Admin PDF management

- Adds `Admin -> Career Dossier` at `/admin/resume`.
- Adds compact PDF settings without duplicating Journey or Wiki content.
- Web View PDF and Download CV PDF can be the same Media Library asset or two separate PDFs.
- Adds editable action labels, document title/description, dossier enabled state and document-card visibility.
- Uses AJAX/server-action save with draft protection and save feedback.
- Extends Media Library to accept PDF uploads alongside images, videos and ZIP archives.
- PDF assets are identified clearly as PDF files in MediaPicker.
- Adds `/api/resume/download` so R2-hosted CV files are returned with `Content-Disposition: attachment` instead of relying on cross-origin browser download behavior.
- The download endpoint accepts only the bundled CV or a PDF registered in Media Library.

## SEO

- Adds a canonical `/resume` metadata definition with index/follow enabled.
- Adds ProfilePage + Person JSON-LD using the public identity and Wiki aliases.
- The route remains included in the existing sitemap.

## Release

- Version: `1.1.89`.
- No Prisma migration.
- No dependency changes.
- Existing updater and N0C compatibility behavior remain unchanged.
