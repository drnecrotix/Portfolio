# v1.2.2

Gallery navigation and viewing modes cleanup.

## Gallery navigation

- Gallery cards no longer open an intermediate fullscreen lightbox.
- Clicking a work in Rows, Grid or Slider opens its `/gallery/[slug]` detail page directly.
- The detail page remains the single place for the full media viewer, work metadata, video embeds and NSFW reveal behavior.
- Removes the obsolete Gallery lightbox component after direct navigation becomes the default flow.

## Grid view

- Replaces the remaining editorial mosaic spans with a balanced responsive grid.
- Uses consistent 4:3 cards with 1 / 2 / 3 / 4 columns across mobile, tablet, desktop and very wide desktop layouts.
- Keeps Creative Type badges, titles, video indicators, NSFW blur and hover treatment.
- Removes irregular feature/wide spans that could create awkward gaps or visually oversized cards.

## Slider view

- Replaces Infinite Preview with a horizontal snap slider.
- Slider cards preserve the real Gallery thumbnails, Creative Type, title, description and NSFW blur behavior.
- Adds previous/next controls while keeping touchpad, touch and horizontal scrolling available.
- Slider cards open the full work directly.
- Removes the old InfiniteImageField implementation after it is no longer used.

## Interface settings

- Removes the unused visible `View` form from Gallery Interface.
- Renames the remaining forms to explain exactly where each label appears:
  - All filter label
  - Rows sidebar heading
  - Grid load more button
  - No results message
  - Rows view tooltip
  - Grid view tooltip
  - Slider view tooltip
- Adds short helper text below each Interface field.
- Preserves the existing tab-scoped save protection, so Interface changes cannot overwrite Works or Page content.
- Existing `Infinite Preview` tooltip values are presented as `Slider View` and are migrated on the next Interface save.

## Release

- Version `1.2.2`.
- No Prisma migration.
- No new dependencies.
