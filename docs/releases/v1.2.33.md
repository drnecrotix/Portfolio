# Portfolio v1.2.33

## Mobile reading progress

- Fixes the Blog reading progress indicator not appearing reliably on mobile browsers.
- Uses `visualViewport` when available so the active reading zone follows the actually visible browser viewport while the address and browser bars expand or collapse.
- Recalculates on both layout-viewport and visual-viewport scroll/resize events.
- Handles short publications separately so the progress indicator can still become visible when the entire article is shorter than the normal reading window.
- Keeps long-publication progress based on the article body rather than the surrounding page.
- Raises the progress layer above public mobile navigation/overlays and gives the mobile rail a wider, safer bottom offset above the device safe area.
- Keeps the indicator hidden before the reading zone and after the publication has been passed.
- Keeps desktop behavior intact while using mobile-specific viewport measurements only when the browser exposes them.

## Mobile Blog archive

- Removes the native horizontal scrollbar shown under the publication-tag rail in mobile Chrome/Safari/Firefox.
- Compacts the Journal introduction on narrow screens without changing the desktop composition.
- Keeps the publication count inline instead of consuming a separate tall block.
- Reduces vertical space around the tag rail and result summary.
- Keeps search full width while placing category and sort controls side by side on mobile.
- Moves the existing FlowingMenu publication list higher so publication content is visible sooner on the initial mobile viewport.
- Preserves the existing tag arrows, filters and FlowingMenu visual identity.

## Compatibility

- No Prisma migration.
- No Post schema changes.
- No changes to quote styling or traffic analytics.
- Desktop Blog archive layout remains unchanged.
