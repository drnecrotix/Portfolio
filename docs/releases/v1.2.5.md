# v1.2.5

Smoother first-visit `Niko` loading animation.

## Niko intro

- Preserves the existing `Niko` signature typography, scale, white text treatment, underline and dark glow background.
- Removes the old full-screen slide-up exit that made the intro feel like a slider panel.
- Replaces it with a soft dissolve using opacity, subtle scale and blur.
- Softens the text entrance with a restrained blur-to-sharp fade and only minimal vertical movement.
- Lets the ambient cyan and violet glow fields fade naturally with the intro instead of being carried off-screen.
- Keeps the first-visit-only behavior unchanged.

## Release

- Version `1.2.5`.
- No Prisma migration.
- No new dependencies.
- No changes to the secondary route loader or page layouts.
