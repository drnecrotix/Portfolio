# Portfolio v1.2.37

## Admin settings workbenches

- Reworks selected Admin settings pages as focused editor workbenches instead of landing-style settings screens.
- Uses layout ideas inspired by popular open-source products such as Plane and Twenty: persistent section navigation, dense editing surfaces, clear save boundaries and contextual preview panes.
- Keeps the existing Admin visual language rather than copying external project styling.

## General Settings

- Replaces the long stacked settings page with a section rail for Identity, Appearance, Page access, Contact, Social and Regional settings.
- Adds a sticky live preview that changes with the active settings section.
- Identity preview updates the site name, description and favicon immediately.
- Appearance uses visual Night/Day selectors instead of a plain theme dropdown and previews the accent color in context.
- Page availability is now a visual segmented control for Public, Admin only and Off, with a matching route-status preview.
- Contact, social profiles, locale and timezone have contextual previews while editing.
- Keeps the existing save actions, validation rules and public cache refresh behavior.

## Homepage profile card

- Adds an independent Profile card name setting instead of forcing the card to use the global site name.
- Leaving the field empty preserves the existing site-name fallback.
- Profile title, description, image and social links keep their existing behavior.

## Blog Journal appearance

- Moves the Blog appearance editor to a compact Heading / Rotation workbench.
- Keeps the Blog hero live preview permanently visible on wide screens instead of using a large preview card before the form.
- Preserves title effects, rotating phrases, timing controls and the existing Blog appearance storage format.
- Uses a compact page header instead of a landing-page style introduction.

## Footer & More info

- Replaces the long stack of footer setting cards with Compact bar, Marquee, Navigation, Social and Regional sections.
- Adds a live preview switch between the compact public footer and the expanded More info content.
- Preview updates brand text, compact animation labels, marquee phrases, navigation labels, social/contact content, local time and edition text while editing.
- Keeps the protected public footer layout, animation and responsive behavior unchanged.

## Compatibility

- No Prisma migration.
- No settings schema changes.
- Existing server actions and validation remain in place.
- Navigation dropdown visual settings from v1.2.35/v1.2.36 are not changed.
- Protected visual changes are intentionally included in this release and are covered by the PR design approval and CI visual checks.
