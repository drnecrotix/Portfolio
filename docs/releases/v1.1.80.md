# Portfolio v1.1.80

## API Integrations center

- Added **Tools → API Integrations** for OWNER/ADMIN users.
- Central status and configuration for GitHub, WakaTime, OpenAI, Groq, Google Gemini, OpenRouter and Cloudflare R2.
- Each integration explains what it is used for inside the portfolio.
- Added per-integration **Test connection** and global **Test all** actions.
- Test results persist the last status, message, timestamp and latency.
- Shows whether each credential currently comes from API Integrations CMS, AI Assistant CMS, environment variables or is missing.

## Secure credential storage

- Added `SiteSettings.integrationSettings` JSON storage.
- CMS credentials are encrypted with AES-256-GCM before being stored in PostgreSQL.
- Encryption uses `INTEGRATION_CREDENTIALS_SECRET`, then falls back to `AI_CREDENTIALS_SECRET` or `AUTH_SECRET`.
- Secret values are never returned to the browser after they are stored.
- CMS credentials override environment variables at runtime.

## Runtime integration updates

- GitHub Lab proof now accepts the GitHub token saved in API Integrations.
- GitHub stats and language statistics use the same runtime credential resolver.
- WakaTime endpoints accept the CMS-managed WakaTime key.
- AI provider keys saved in API Integrations are synchronized with the existing AI Assistant encrypted vault.
- Cloudflare R2 media uploads can use CMS-managed R2 credentials and fall back to environment configuration.

## Database / deployment

- Adds one Prisma migration for `SiteSettings.integrationSettings`.
- No dependency changes.
- Compatible with the existing Admin updater and N0C WASM build flow.
