# v1.1.82 - Personal Wiki

## Personal Wiki

- Adds a new public `/wiki` page designed as a personal, Wikipedia-inspired knowledge base while preserving the visual language of the portfolio.
- Uses a three-column desktop composition with sticky contents navigation, long-form article content and a profile infobox.
- Uses a compact mobile layout with a collapsible table of contents and the infobox stacked naturally below the article.
- Adds a maintained `Updated` marker, aliases, quick facts, chronology and related-page cards.
- Uses the configured public profile identity and social links as fallbacks where appropriate.

## CMS

- Adds `Admin → Personal Wiki` at `/admin/wiki`.
- Wiki content is stored in the internal Page record `__personal-wiki-config` and remains hidden from the generic Pages manager.
- The internal record is stored as `DRAFT`, so it cannot leak through the generic `/pages/[slug]` renderer.
- Adds editable page identity, introduction, portrait through Media Library, aliases, infobox facts, article sections, chronology, related links and footer note.
- Article sections, facts, timeline entries and related links can be reordered, hidden or removed.
- Major modules can be enabled or disabled independently.

## Navigation and SEO

- Personal Wiki can be enabled/disabled publicly from its CMS page.
- `Show Wiki in public navigation` creates or updates a real `/wiki` navigation item so it remains editable from the existing Navigation manager.
- Before the first CMS save, the navigation API can expose a virtual Wiki item using the default configuration.
- Adds `/wiki` to the sitemap only while the page is enabled.
- Excludes `__personal-wiki-config`, `__experience-config` and `__journey-entry-state` from generic sitemap page entries.

## Release

- Version bumped to `1.1.82`.
- No Prisma migration.
- No new dependencies.
- Compatible with the existing production updater and N0C WASM build path.
