# Portfolio v1.3.0

## SEO Intelligence

- Adds `/seo-intelligence` as a new NecrotixLab Web Health / SEO research workspace.
- Adds four focused DataForSEO-backed modes: Keyword Research, Google SERP / Rank Check, Organic Competitors and Backlinks Overview.
- Defaults search-market requests to Bulgaria (`location_code: 2100`) and Bulgarian (`language_code: bg`).
- Keeps DataForSEO credentials server-side and supports `DATAFORSEO_LOGIN` / `DATAFORSEO_PASSWORD` runtime configuration.
- Uses the existing integration runtime so encrypted CMS values can override environment values when DataForSEO fields are added to API Integrations.
- Adds same-origin protection, no-store responses, a five-requests-per-ten-minutes IP limit and a two-request concurrency cap for paid API calls.
- Limits keyword/SERP results to 20 and competitor results to 12 to keep both API cost and UI noise bounded.
- Highlights a requested target domain in SERP results without exposing credentials to the browser.
- Adds SEO Intelligence to the shared Web Health navigation.
- Adds unit coverage for domain normalization/target matching and visual smoke coverage for the public SEO Intelligence page.
- Documents the DataForSEO server environment variables in `.env.example`.

The initial release intentionally avoids automated recurring rank tracking or background API polling. Those features require explicit persistence, scheduling and cost controls before they are enabled.
