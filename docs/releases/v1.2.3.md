# v1.2.3

Gallery slider interaction and detail-page balance improvements.

## Slider view

- Preserves original thumbnail proportions with `object-contain` instead of forcing images into a cropped 16:9 presentation.
- Uses a taller responsive media stage for portrait, landscape and mixed-aspect works.
- Adds mouse drag / grab navigation.
- Adds mouse-wheel horizontal navigation while the pointer is over the slider.
- Keeps touch and swipe support.
- Adds a position scrubber for direct navigation through larger collections.
- Shows the active work number and total count.
- Previous / next buttons now track the active slide and disable at the ends.
- Prevents accidental navigation when a user drags a slide instead of clicking it.
- Keeps NSFW previews blurred and links every slide directly to the full work page.

## Work detail layout

- `About this work` is now always rendered so the detail page keeps a balanced two-column composition.
- Empty Story fields display a restrained `No content` placeholder with the message `No additional story has been added for this work yet.`
- Gives the About section a card treatment and minimum desktop height to better balance the Work details panel.
- Tags use a matching card below the About section when present.

## Release

- Version `1.2.3`.
- No Prisma migration.
- No new dependencies.
