# Portfolio v1.2.39

## Blog image protection

- Extends watermark coverage from only the first Blog image to the featured image and inline article images.
- Keeps watermarking active for inline article images even when a publication has no featured image.
- Prevents protected Blog images from opening the existing featured-image or article-image lightboxes, so the watermark remains on the visible image surface.
- Blocks normal click, auxiliary-click, context-menu, drag and Enter/Space activation paths on protected Blog image hosts.
- Marks protected images as non-draggable and disables selection/drag cursor behavior.
- Keeps related-publication thumbnails interactive by excluding Blog navigation links from the protected-image scope.
- Does not change Gallery or Project image interaction behavior.

## Compatibility

- No Prisma migration.
- No Post schema changes.
- Existing watermark configuration remains compatible.
- Protection is a browser-side deterrent and does not make public image URLs inaccessible to developer tools or network inspection.
