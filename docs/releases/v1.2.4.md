# v1.2.4

Gallery interaction, route-scroll, homepage and loading-animation polish.

## Gallery slider

- Replaces the React `onWheel` handler with a native `wheel` listener registered with `{ passive: false }`.
- Keeps mouse-wheel horizontal navigation while allowing `preventDefault()` to work correctly.
- Removes repeated `Unable to preventDefault inside passive event listener invocation` console errors.
- Preserves drag, swipe, buttons, scrubber navigation and the existing Gallery layout.

## Route scroll

- Resets the root Lenis scroll position whenever the pathname changes.
- Prevents Blog posts, Project details and other internal routes from inheriting the previous page's scroll position.
- Applies an immediate browser + Lenis reset and confirms it after the new route has committed.
- Hash-only navigation is unaffected because it does not change the pathname.

## Homepage Journal and Projects

- Removes the forced `100svh` vertical centering from the Journal and Projects sections so short lists no longer create a large empty dead zone between them.
- Keeps the existing list visual language while making both sections content-driven with responsive spacing.
- Replaces the aggressive whole-home wheel snapping with a desktop-only assist around the Journal / Projects boundary.
- Leaves mobile, touch devices and reduced-motion users on native scrolling behavior.
- Limits the homepage Journal to at most 5 newest publications.
- Limits the homepage Projects section to at most 5 newest non-archived projects.
- Keeps the full Blog and Projects archives unchanged on their dedicated pages.
- Caps the matching Homepage Admin list controls at 5 so the setting cannot later grow the landing page into an oversized list.

## Route loading

- Replaces the split-panel / slider-like route loader with a text-free generative signal constellation.
- Builds an abstract network of animated nodes and connecting paths instead of sliding the screen open from the sides.
- Adds a restrained radial grid, signal pulses and a short light-bloom dissolve when the destination page is ready.
- Keeps page names and slugs out of the loader.
- Keeps the separate first-visit homepage `Niko` intro, while making its motion smoother and removing its old full-screen slide-up exit.
- Preserves the existing `Niko` typography, scale, signature font treatment, underline and dark glow background.
- Uses a soft fade / blur-to-sharp entrance and a gentle dissolve / blur exit instead of moving the whole screen like a slider panel.
- Keeps the existing preload context, Lenis scroll lock and reduced-motion behavior.

## Console notes

- Grammarly `Permissions policy violation: unload is not allowed in this document` messages are generated by the Grammarly browser extension, not by the Portfolio application.
- Chromium's `powerPreference option is currently ignored ... on Windows` message is a browser/WebGPU implementation notice and does not indicate an application failure.
- The iframe `allow` / `allowfullscreen` message is a non-breaking browser compatibility warning; fullscreen permission remains granted through the `allow` policy.

## Release

- Version `1.2.4`.
- No Prisma migration.
- No new dependencies.
- No protected visual layout changes outside the requested homepage Journal / Projects spacing adjustment.
