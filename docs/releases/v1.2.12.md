# v1.2.12

Improves country attribution, traffic analysis, A/B experiment interpretation and Admin Dashboard clarity.

## Country attribution and privacy

- Keeps hosting/CDN country headers as the preferred source for country analytics.
- Adds a fallback that reads the public client IP from trusted request headers when a country header is unavailable.
- Stores the raw IP only in the short-lived `TrafficSession` record and uses it to resolve an ISO country code.
- Uses `country.is` only for IP-to-country fallback requests.
- Does not collect city or precise coordinates.
- Removes short-lived traffic-session records, including stored raw IP addresses, after about 24 hours of inactivity.
- Keeps country/device aggregate traffic for up to about 31 days.
- Keeps Do Not Track handling for public page-view analytics.
- Updates Privacy & GDPR and Cookie Policy disclosures for the new fallback.

## Traffic analytics

- Adds country-coverage diagnostics so the Admin UI shows how much traffic was successfully attributed.
- Makes the Audience & traffic timeline interactive with selectable points.
- Shows page opens, sessions, pages per session and selected-period traffic share.
- Keeps the Dashboard Monday-to-Sunday weekday view and clearer `Page opens` / `Sessions` terminology.
- Makes Top countries clearer and explains when older traffic remains unattributed.

## Experiments

- Adds 95% Wilson confidence intervals for A/B conversion rates.
- Adds an approximate two-proportion comparison for stronger statistical context.
- Shows absolute conversion difference, relative lift, descriptive evidence and sample balance separately.
- Gives Variant A a restrained violet treatment and Variant B a restrained sky treatment while preserving readable text contrast.
- Surfaces split warnings at page level with the exact affected test and A/B allocation.
- Repeats the split warning inside the affected test so its source is immediately visible.
- Keeps supporting events and method details collapsible to reduce visual clutter.

## Admin Dashboard

- Removes the Quick Access block and its Dashboard code.
- Keeps Portfolio Updates content-sized instead of stretching to match the adjacent Site Health card.
- Replaces the cache-purge redirect with an in-place server action so the Dashboard does not flash through a white reload state.
- Shows inline cache purge success or failure feedback.

## Database

`20260904121500_traffic_ip_country_lookup`

The migration adds nullable `ipAddress` and `countryLookupAt` fields to the short-lived `TrafficSession` model.
