# v1.1.99 - Gallery tags, social thumbnails and NSFW previews

## Gallery tags

- Turns Gallery tags into working public navigation instead of decorative labels.
- Tag chips on a work page link to `/gallery/tag/<tag>` filtered views.
- Tag routes preserve the normal Creative Type filters and Gallery presentation.
- Gallery Admin search now matches tags as well as titles, slugs and Creative Types.
- Tag input removes a leading `#`, trims values, removes duplicates and keeps the existing 30-tag limit.
- Tag pages are intentionally `noindex, follow` to avoid thin duplicate index pages while still allowing navigation.

## Social and video thumbnails

- Keeps the original public social URL separately from the embed URL so thumbnail refresh continues to work after saving.
- Resolves canonical source URLs and embed URLs before persisting a social video entry.
- Supports YouTube, Vimeo, TikTok, Instagram, Facebook, X/Twitter, Pinterest and Dailymotion workflows.
- Uses direct YouTube thumbnails where possible.
- Uses oEmbed thumbnail data for Vimeo, TikTok, Pinterest and Dailymotion.
- Uses safe Open Graph/Twitter metadata fallback for supported social hosts when no dedicated oEmbed flow is available.
- Supports safe short-link resolution such as TikTok `vm.tiktok.com` and Pinterest `pin.it` before building thumbnails/embeds.
- Restricts fetched social hosts and accepted remote thumbnail CDN hosts to an allowlist.
- Keeps a custom thumbnail picker as a fallback when a platform does not expose a usable preview image.
- Stops using a video embed URL as an image source when no thumbnail exists; the Gallery now renders a video placeholder instead of a broken image.

## NSFW preview mode

- Adds a per-work `NSFW preview` toggle in Gallery Admin.
- Keeps the original media unchanged and applies the restriction only to public preview presentation.
- Blurs the real thumbnail and adds a clear `NSFW` overlay in Gallery Grid and Rows views.
- Keeps NSFW content concealed inside the Gallery lightbox and exposes the real work only through `View full work`.
- Excludes NSFW images from Infinite Preview so the canvas cannot accidentally reveal the original image.
- Uses a neutral NSFW social preview in Open Graph/Twitter metadata and structured data rather than exposing the original media URL.
- Prevents original NSFW image URLs from being published as Gallery image entries in the sitemap.

## Media protection scope

The NSFW feature is a presentation/privacy layer, not DRM. Existing local Media Library uploads remain under public storage and existing R2 storage uses its configured public base URL. A stronger OnlyFans/Fansly-style delivery model requires private object storage with short-lived signed delivery URLs and, for stronger video protection, tokenized streaming such as signed HLS/DASH playback. This release does not silently migrate or break existing Media Library assets.

## Compatibility

- Version `1.1.99`.
- No Prisma migration.
- No new dependencies.
- Existing Gallery entries remain backward compatible.
- Existing local and R2 Media Library behavior remains unchanged.
- Homepage slider, Articles layout and Projects layout are not redesigned.
