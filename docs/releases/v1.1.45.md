# Portfolio v1.1.45

Security-hardening maintenance release focused on reducing false-positive and real attack surfaces related to deceptive-content / Safe Browsing classifications.

## Security hardening

- Adds `noindex`, `nofollow`, `nocache` and restrictive Googlebot metadata to `/admin/login`.
- Adds `X-Robots-Tag` headers for `/admin/*` and `/api/*`.
- Adds site-wide security headers:
  - Content-Security-Policy
  - X-Content-Type-Options
  - X-Frame-Options
  - Referrer-Policy
  - Permissions-Policy
  - Cross-Origin-Opener-Policy
- Restricts framing of the Portfolio itself with `frame-ancestors 'none'` / `X-Frame-Options: DENY`.
- Restricts public Gallery video iframes to normalized embeds from trusted providers only.
- Arbitrary external video URLs are no longer passed directly into public iframes.
- Unresolved TikTok/Pinterest short links and unsupported provider URLs are rejected instead of embedded directly.

## Supported Gallery embed providers

- YouTube
- Vimeo
- TikTok (canonical video URLs)
- Instagram
- Facebook
- X / Twitter
- Pinterest (canonical pin URLs)
- Dailymotion
- Local same-site media URLs

## Google Safe Browsing note

This release reduces potential security and deceptive-content triggers but cannot guarantee removal of an existing Google Safe Browsing warning. A Search Console Security Issues review and verification of production-hosting files remain required when Google has already classified the site.

## Upgrade

No Prisma schema migration is required. The version bump from 1.1.44 to 1.1.45 makes this release detectable by the existing Admin Dashboard updater.
