# Portfolio v1.2.59

## Kreatrics Web Health Suite

- Adds Email Domain Security for public MX, SPF, DMARC, selector-specific DKIM, MTA-STS, TLS-RPT, CAA and BIMI signals.
- Adds a bounded same-origin Site Crawl for broken internal pages, redirects and page-title hygiene, capped at eight pages and one active crawl per Passenger process.
- Adds a lightweight Accessibility Check for static HTML signals such as document language, image alternatives, labels, accessible names, heading structure, duplicate IDs and landmarks.
- Keeps the existing Website Inspector flat technical-report design and adds a compact Web Health Suite navigation rail instead of dashboard cards.

## Customer service workflow

- Adds Request a professional fix to Website Inspector and all three new Web Health tools.
- Automated service ranges are non-binding and recalculated server-side from selected warning/failure findings.
- Ordinary scans are not stored. Audit details and contact information are persisted only after the visitor explicitly submits a service request and accepts the privacy notice.
- Adds a ServiceRequest PostgreSQL model with reference IDs, selected findings, estimates, final quote, customer context, internal notes and lifecycle status.
- Adds Admin > Commerce > Service Requests for OWNER/ADMIN users.
- Adds best-effort SMTP notification for new requests without making email delivery a prerequisite for database persistence.

## Safety and resource controls

- New URL tools use SSRF-safe public HTTP/HTTPS requests with private/local/reserved network blocking, standard-port enforcement, response caps and request timeouts.
- Site Crawl is same-origin only and does not enumerate hidden paths, authenticate, scan ports or run exploit payloads.
- Email Domain Security reads public DNS only and never sends mail.
- Accessibility Check is explicitly a static automated sample, not WCAG certification.
