# Portfolio v1.2.46

## NecrotixLab Digital Footprint

- Adds a public self-audit module for email, account, breach, domain and browser exposure.
- Requires one-time email ownership verification before identity providers run.
- Uses encrypted short-lived verification records and does not persist scan results.
- Adds provider adapters for HIBP, Holehe, EmailRep, Gravatar, GitHub and curated public username checks.
- Adds a local password exposure check using the HIBP k-anonymity range model; passwords never leave the browser.
- Normalizes findings into a single risk report with confidence, evidence and remediation guidance.
- Keeps secret values, passwords, session data and authentication tokens out of reports and logs.
- Adds encrypted SMTP configuration and connection testing in Admin > API Integrations for ownership-code delivery.
