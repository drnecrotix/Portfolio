# v1.1.72 - Compact Experience & Partners Showcase

## Compact Experience navigation

- Replaces the oversized Education, Journey and Experience cards with compact pill-style controls inspired by the original Experience page.
- Shows the active view description separately above the controls instead of repeating long descriptions inside large cards.
- Reduces vertical spacing around the selector so the selected Experience content begins sooner.
- Keeps CMS-provided labels, descriptions, default tab and visibility controls intact.

## Partners & Sponsors showcase

- Redesigns the former `Selected experience` logo area as a compact `Partners & Sponsors` showcase.
- Replaces the two oversized logo rows with one clean horizontal strip.
- Normalizes logo sizing, contrast and card treatment for a more consistent partner-wall appearance.
- Reduces the section height and removes the large empty areas around the logos.
- Migrates the legacy default `Selected experience` title to `Partners & Sponsors` without overwriting custom marquee titles saved from the admin panel.

## Compatibility

- Keeps the restored v1.1.71 Journey timeline unchanged.
- Keeps `/admin/experience` and all Experience CMS controls.
- No Prisma migration is required.
- No dependency changes are required.
- Bumps Portfolio from `1.1.71` to `1.1.72` for Admin Dashboard updater detection.
