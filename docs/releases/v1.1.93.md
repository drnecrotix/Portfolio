# v1.1.93 - Visual Portfolio SEO

## Gallery

- Expands Gallery into a visual portfolio for Photography, Photoshoot, Drawing, Painting, Digital Art, Mixed Media and Video.
- Adds optional multi-image series so one Gallery entry can represent a complete photoshoot, artwork details or a visual collection.
- Adds editable slug, category, alt text, story, tags, artist, photographer, model/subject, location, creation date, medium, dimensions, software, camera, lens, copyright and license metadata.
- Keeps existing Gallery rows, grid, infinite view and lightbox presentation intact.
- Adds a small `View full work` action inside the existing lightbox to open the dedicated work page.
- Existing Gallery records remain compatible and receive safe defaults when the new fields are absent.

## Search and discovery

- Renders `/gallery` from server-loaded Gallery content so crawlers receive the real portfolio data in the initial response.
- Adds dedicated `/gallery/[slug]` pages for individual artworks, photographs, photoshoots and videos.
- Adds canonical metadata, robots controls, OpenGraph/Twitter metadata and per-work SEO title/description overrides.
- Adds `CollectionPage`, `ItemList`, `VisualArtwork`, `Photograph`, `CreativeWork` and `ImageObject` structured data where appropriate.
- Adds indexable Gallery work URLs and their images to the automatic sitemap, including images from photoshoot/series entries.
- Adds separate `Public` and `Index` controls so a work may be publicly accessible while remaining `noindex` and excluded from the sitemap.
- Revalidates Gallery detail routes and the sitemap immediately after Gallery settings are saved.

## Scope protection

- Homepage slider components and homepage slider presentation are not changed.
- Blog/Article visual components and layouts are not changed.
- Project visual components and layouts are not changed.

## Release

- Version: `1.1.93`.
- No Prisma migration.
- No dependency changes.
