# v1.1.75 - Blog views

## Public blog
- Adds a Views counter beside Like and Share in every public blog publication.
- Views are recorded asynchronously after the article opens, without reloading the page.
- A publication is counted once per browser session to avoid inflating the metric on refresh.
- View increments are atomic in PostgreSQL.
- Large counters use a compact social-style format with a decimal comma where needed: `1,2K`, `12,8K`, `1,1M`.
- Like counts use the same compact formatter so the action row stays balanced on narrow screens.

## Database
- Adds `Post.viewCount` with a default value of `0`.
- Includes migration `20260902120000_blog_post_views`.

## Release / updater
- Version bumped to `1.1.75`.
- The existing updater will deploy the included Prisma migration before the production build.
- No new dependencies.
