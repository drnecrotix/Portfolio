# v1.1.57 - Updater resilience and blog polish

- Prevent transient update-check failures from escalating into a React error page.
- Retry the read-only update check once after a short delay when the server action transport is interrupted.
- Keep install requests non-retrying to avoid starting duplicate update workers.
- Convert interrupted install requests into an in-dashboard error state instead of an uncaught page error.
- Delay the automatic dashboard update check slightly to reduce startup/Passenger race conditions.
- Remove the duplicated author footer from individual blog posts.
- Apply the minimal editorial comments layout that was prepared after v1.1.56 merged.
- No Prisma migration required.
