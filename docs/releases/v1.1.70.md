# v1.1.70 - Customizable Experience

## Experience CMS

- Adds a dedicated `/admin/experience` editor for the public `/experience` page.
- Makes the Experience page CMS-driven while keeping safe defaults when no saved configuration exists.
- Adds visibility toggles for the page, hero, decorative background, marquee, tab navigation, Education, Journey, Experience archive and highlight sections.
- Adds per-card visibility controls for skills, responsibilities, impact and key learnings.
- Allows editing hero copy, CTA labels and URLs, tab labels and descriptions, archive copy, empty states and marquee text.
- Allows Experience archive categories to be enabled or disabled, renamed and mapped to custom ID prefixes without deleting their content.
- Allows each Education, Journey and Experience highlight block to be enabled independently and edited from the admin panel.
- Preserves disabled content so sections can be restored later without re-entering data.

## Admin and updater readiness

- Adds Experience to the protected Content navigation.
- Stores Experience configuration in an internal CMS page record and keeps that record out of the standard Pages list.
- Bumps the Portfolio version to `1.1.70` so the admin GitHub updater detects this release after it reaches `main`.
- Uses only icons available in the currently pinned `lucide-react` version so typecheck and production builds remain compatible.

## Deployment

No Prisma schema migration is required for this release. The existing updater can deploy it through the admin dashboard after the PR is merged into `main`.
