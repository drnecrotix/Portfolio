# Portfolio v1.2.51

## Digital Footprint: real exposed values and related accounts

- Breach findings now include structured **exposedData** (breach name, date, domain, record counts, verified/sensitive flags, data classes, matched identifier) — not only field type labels.
- Account and reputation providers always attach key/value **exposedData** when public APIs return profile metadata.
- Email lookups also probe public profiles using the email local-part and usernames discovered from GitHub / GitLab / Gravatar / Holehe results.
- Related accounts list aggregates account findings (GitHub, GitLab, Gravatar, Holehe services, public profiles) with per-account exposed fields.
- Result rows preview the first exposed key/value pairs; the details dialog shows the full map.
- Deduplication merges exposedData from matching breach sources.

Note: public breach APIs never return raw passwords or full dump rows. Values shown are public provider metadata and public profile fields only.
