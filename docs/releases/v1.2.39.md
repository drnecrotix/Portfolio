# Portfolio v1.2.39

## Blog image protection

- Keeps watermark coverage on the featured image and inline article images instead of limiting it to only the first image.
- Keeps watermarking enabled for article images even when a publication has no featured image.
- Disables normal click/keyboard image preview paths inside protected Blog content so the watermark cannot disappear into an unwatermarked lightbox.
- Blocks context-menu and drag interactions on protected Blog images and marks them as non-draggable.
- Keeps related-publication thumbnails interactive and outside the protected-content interception path.
- Adds protected-image cursor and browser drag-selection styling without changing Gallery or Project image behavior.

## Compatibility

- No Prisma migration.
- No Post schema changes.
- Existing watermark settings remain valid.
- Image protection is a browser-side deterrent and does not make public image URLs inaccessible to developer tools or network inspection.
