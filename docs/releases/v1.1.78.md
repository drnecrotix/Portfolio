# v1.1.78 - The Lab

## The Lab replaces Skills

- Adds the new canonical `/lab` page.
- Keeps the existing 3D Spline robot as the visual center of the hero.
- Keeps floating technology icons around the robot and makes them interactive.
- Replaces the generic Skills presentation with a capability-first experience.
- `/skills` now permanently redirects to `/lab` and is no longer indexed as a separate page.

## New Lab structure

- Capabilities - Product & Web Engineering, Backend & Data Systems, Infrastructure & Hosting, AI & Automation, Design & Creative Technology, and Community & Interactive Systems.
- Toolchain - a compact technology matrix without arbitrary proficiency percentages.
- Proof, not percentages - derives frequently used technologies from actual portfolio project data and links the stack concept to real work.
- Currently Exploring - highlights active areas of experimentation.
- Lab Philosophy - closes the page with a project-focused CTA.

## Navigation and SEO

- Updates navigation fallbacks and default navigation seeds from Skills to Lab.
- Normalizes existing `/skills` navigation records to `/lab` at runtime.
- Updates Footer defaults and legacy saved Skills links to Lab.
- Adds `/lab` to the sitemap with canonical metadata.

## Skills runtime fixes

- The obsolete Skills route no longer loads the external Popsy illustrations whose host currently returns an invalid TLS certificate.
- CSP `media-src` now permits `data:` media required by the existing Spline runtime, in addition to self, blob and HTTPS sources.
- The new Lab technology icons use the existing jsDelivr Devicon source instead of the failing Popsy host.

## Updater

- Version bumped to `1.1.78`.
- No Prisma migration.
- No dependency changes.
- Compatible with the existing Admin updater and N0C WASM build flow.
