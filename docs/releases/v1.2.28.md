# Portfolio v1.2.28

## Blog reading polish

- Keeps the v1.2.27 Blog archive and publication structure intact while refining the reading experience.
- Reworks rich-text blockquotes into a fuller editorial card with a soft gradient surface, rounded border, accent rail, depth and a decorative quotation mark.
- Preserves authored quote alignment and paragraph structure instead of forcing a new text layout.
- Keeps multi-paragraph quotes readable by only trimming the first and last paragraph margins.

## Reading progress

- Makes the publication reading-progress indicator a persistent fixed bar at the very top of the viewport.
- Raises the progress layer above the fixed navigation so it no longer disappears behind the header while scrolling.
- Adds a visible track behind the progress fill and a smoother 0-100% transition.
- Exposes proper progressbar semantics for assistive technologies.

## Blog tag navigation

- Adds previous/next arrow controls around the horizontal tag rail on `/blog`.
- Scrolls tags by a useful viewport-sized step instead of requiring precise horizontal dragging.
- Disables arrows automatically at the beginning and end of the rail.
- Adds subtle edge fades whenever additional tags exist outside the visible area.
- Automatically brings the selected tag into view.
- Keeps native touchpad/touch horizontal scrolling available.
- Shows the currently selected tag as a compact removable filter chip beside the publication count.

## Compatibility

- No Prisma migration.
- No Post schema changes.
- Existing publications, tags, categories, translations and Tiptap content remain compatible.
