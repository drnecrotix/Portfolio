# v1.1.98 - Gallery polish and mobile fixes

## Creative Types

Gallery Creative Type choices are simplified to the set that best fits the portfolio:

- Photography
- Traditional Art
- Digital Art
- Video
- Other

Traditional Art replaces the separate Drawing and Painting choices and also absorbs Mixed Media for a cleaner taxonomy. Existing Drawing and Mixed Media records normalize to the existing painting-backed Traditional Art type, while existing Painting records are presented as Traditional Art. Existing metadata is preserved.

## Work details presentation

- Refines the public Work details card into a more compact metadata panel.
- Uses cleaner sans-serif typography for the metadata block.
- Aligns labels and values on a consistent baseline with stable column proportions.
- Improves wrapping, spacing and readability on narrow screens and desktop.
- Keeps type-specific metadata behavior from v1.1.97 unchanged.

## Gallery viewer mobile polish

- Hides the desktop zoom-help sentence on mobile so it cannot collide with the watermark.
- Gives the watermark a dedicated bottom-right safe area with smaller mobile typography and spacing.
- Compacts the mobile zoom toolbar.
- Hides the zoom percentage/reset label on small screens while keeping the zoom buttons and rotate control available.
- Keeps the full zoom hint and percentage control on larger screens.

## Compatibility

- No Prisma migration.
- No dependency changes.
- Existing Gallery media and metadata remain compatible.
- Homepage slider, Articles layout and Projects layout are not redesigned.
