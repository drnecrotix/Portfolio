# v1.1.97 - Type-aware Gallery work details

## Gallery admin

- Keeps the compact list-first Gallery workspace.
- Uses Creative Type as the single public Gallery taxonomy.
- Removes the duplicate Photoshoot Creative Type; existing Photoshoot entries migrate to Photography at normalization time.
- Media kind is derived automatically from Creative Type, so editors no longer choose both Media type and Creative type.

## Type-aware Work details

Work details now adapt to the selected Creative Type and only relevant metadata is presented in Admin and on the public work page.

- Photography: photographer, model/subject, location/date, device type, camera, lens, film stock, sensor/format, focal length, aperture, shutter speed, ISO and lighting.
- Video: video/direction, cinematography, editing, audio/sound, music, text/script, color grading and motion graphics credits, plus location/date, duration, resolution, frame rate and production software.
- Painting: artist, date, medium, materials, technique, surface/support and dimensions.
- Drawing: artist, date, medium, materials, technique, surface/paper and dimensions.
- Digital Art: artist, date, software, device/tablet, technique, canvas dimensions and output resolution.
- Mixed Media: artist, date, medium, materials, technique, surface/support, dimensions and optional software.
- Other: compact generic creative metadata fallback.

Empty Work details remain hidden publicly. Previously entered metadata is preserved if Creative Type changes, but irrelevant fields are not displayed.

## Compatibility

- Legacy Gallery category values remain read-only migration hints only; Creative Type remains the public taxonomy.
- Existing Photoshoot items are treated as Photography without losing media or descriptive content.
- No Prisma migration is required for the Gallery metadata expansion because Gallery settings remain JSON-backed.
