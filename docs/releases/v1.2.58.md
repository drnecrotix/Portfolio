# Portfolio v1.2.58

## Website Inspector expanded audit

- Keeps the existing flat technical-report design and adds new checks as compact report rows.
- Adds TLS protocol, cipher and certificate-expiry details from the existing HTTPS connection.
- Adds redirect-chain reporting and conservative public technology hints.
- Adds bounded robots.txt and XML sitemap discovery checks.
- Adds Open Graph preview checks for title, description and image.
- Adds response-cookie flag review for Secure, SameSite and HttpOnly signals.
- Adds cache-policy and lightweight compression-header checks.
- Adds contextual remediation guidance to actionable warnings and failures.
- Adds a non-invasive WordPress Check for public WordPress signals, exposed core version, REST API status and normal wp-content/wp-includes paths.
- WordPress REST availability is informational and is not treated as a vulnerability.
- Adds a small process-local active-scan cap to reduce outbound request pressure on shared N0C/Passenger hosting.

The inspector remains non-invasive: it does not log in, enumerate WordPress users, brute-force paths, scan ports, run exploit payloads or store submitted URLs/reports. Companion probes are bounded by short timeouts, small response caps and the existing SSRF protections.
