# v1.1.56 - Typography & Writing Tools

## Blog and journal typography

- Adds `@tailwindcss/typography` so existing `prose` and `prose-*` utilities render consistently in published articles and the journal editor.
- Keeps `tailwindcss-animate` enabled alongside Typography.
- Improves headings, paragraphs, links, lists, inline code, code blocks, dividers and pull quotes.
- Public `/blog` archive/list layout is unchanged.

## Writing tools

- Adds Heading 4 / Label to the text-style selector.
- Adds a dedicated Inline code action separate from Code block.
- Makes Quote, Divider, list and link actions clearer.
- Adds Unlink when the cursor is inside a link.
- Improves toolbar grouping, labels and tooltips while retaining alignment, undo, redo and clear-format controls.

## Release

- Package version: `1.1.56`
- No Prisma migration required.
