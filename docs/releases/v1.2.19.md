# Portfolio v1.2.19

## Admin updater hotfix

- Fixes the N0C staged build failure that could occur after a release deletes an App Router page such as `/achievements`.
- The old live `.next/types` tree can contain generated TypeScript files for routes that no longer exist. Those stale files were still picked up during the updater build and caused `Cannot find module .../src/app/achievements/layout.js`.
- Staged updater builds now skip Next.js' duplicate type-check pass only when `NEXT_DIST_DIR=.next-update`. GitHub CI remains the authoritative TypeScript gate before a release reaches `main`.
- The self-update worker now removes only `.next/types` and `.next/dev/types` before building. Runtime chunks and the currently active production build remain untouched until the staged build succeeds.
- CI now reproduces a stale generated route type and verifies that the `.next-update` build completes successfully.

## Upgrade path

- This release is designed to recover installations still on `1.2.17` after the failed `1.2.18` update attempt.
- After `1.2.19` reaches `main`, Admin > Portfolio Updates should report `1.2.19`. Retrying the update uses the incoming `next.config.mjs` during the staged build, so the stale `1.2.18` route-type failure no longer blocks installation.

## Compatibility

- No Prisma schema migration is required.
- No public page or Store design changes are included in this hotfix.
