# v1.1.94

## Gallery layout

- Replaces the large masonry-column Gallery grid with a compact dense editorial grid.
- Gallery cards now use a repeating mix of small, wide, tall and featured sizes.
- Dense grid placement fills available gaps instead of leaving oversized empty areas.
- Existing Gallery item order remains the source of ordering, so moving works up/down in Admin also changes their position in the public grid.
- Desktop Gallery can display up to six compact columns while remaining responsive on tablet and mobile.
- Increases the initial grid batch from 12 to 18 items because the new cards use substantially less vertical space.

## Gallery detail pages

- Reduces the size of the primary media viewer on `/gallery/[slug]`.
- Image works now use one compact viewer for the cover and all additional series images instead of rendering a second large Series masonry section.
- Adds zoom controls from 100% to 400%.
- Supports mouse-wheel zoom, double-click zoom/reset, keyboard `+` / `-`, and drag-to-pan while zoomed.
- Multi-image works include previous/next controls and compact thumbnails below the viewer.

## Watermark

- Adds a subtle watermark in the bottom-right corner of the image viewer.
- Uses the work's Copyright holder when configured and falls back to `NecrotixLab`.
- The watermark is intentionally low-opacity so it remains visible without covering the artwork.
- No right-click blocking is used.

## Compatibility

- No Prisma migration.
- No dependency changes.
- Existing Gallery items and SEO metadata remain compatible.
- Home page slider, Articles and Projects layouts are unchanged.
