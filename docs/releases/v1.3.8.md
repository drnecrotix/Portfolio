# v1.3.8 - Domain-first website configuration

- Moves domain availability to the first step of the website project configurator.
- Adds an option for customers who already have a domain and hosting.
- Hides domain search and removes domain and hosting setup costs when existing infrastructure is selected.
- Suggests alternative domain names when the requested domain is already registered.
- Adds the missing server-side RDAP availability lookup and focused regression coverage.
- Adds a `/services` landing page for website inspection, website creation and support.
- Moves Website Inspector to `/services/website-inspector` while keeping the old URL as a permanent redirect.
- Adds a consistent Back to Lab button to Website Inspector, Website Project and Website Support.
