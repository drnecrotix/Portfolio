# Portfolio v1.2.20

## Store simplification

- Removes the large promotional Store hero and featured/latest showcase from `/store`.
- Opens the Store directly with search, sorting, category filters and the product catalog.
- Keeps the page visually quiet and focused on browsing products without popups, countdowns or aggressive sales UI.
- Preserves an accessible hidden Store heading for page semantics and SEO without adding a visible promotional block.

## Catalog improvements

- Adds product counts to category filters.
- Keeps search and sorting controls in a compact responsive toolbar.
- Uses a consistent product-card grid instead of a widened featured card.
- Retains Featured and Free badges inside the catalog cards where applicable.
- Preserves responsive desktop/mobile behavior and horizontal overflow protections.

## Compatibility

- No Prisma migration is required.
- No changes to checkout, cart, payment-provider, download-grant or Store storage behavior.
- Existing Store products require no data changes.
