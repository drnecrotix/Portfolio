# Portfolio v1.3.4

## Recurring service monitoring

- Upgrades the completed-service monitoring request from a stored preference into a managed recurring monitoring workflow.
- Monitoring plans use `REQUESTED`, `ACTIVE`, `PAUSED` and `CANCELLED` states without adding a new database table; the state remains attached to the existing service request audit snapshot.
- Supports weekly and monthly cadence, recurring EUR price, baseline/latest score, last/next run timestamps, bounded history and last-error state.
- Adds Admin > Service Monitoring for reviewing requests, activating or pausing plans, setting cadence/price and running a check manually.
- Adds an authenticated `POST /api/internal/service-monitoring` scheduler endpoint. Due active checks run sequentially with a maximum of three per scheduler call to protect shared N0C resources.
- Adds `MONITORING_CRON_SECRET` to the environment template. Automatic recurrence requires this secret plus a PlanetHoster cron job that calls the scheduler endpoint; manual monitoring works without cron.
- Customer service status pages now distinguish requested, active, paused and cancelled monitoring and show latest/next check information.
- Adds `docs/service-monitoring.md` with the production scheduler setup and example cron command.

## Service estimates

- Uses the current complexity-aware EUR estimator for service requests: finding-specific complexity, WARN/FAIL severity, bounded affected-item volume, CMS/technology, access availability and bundle adjustments.
- Customer-entered budget remains informational and does not manipulate the automated estimate.
- Final pricing still requires manual review and a confirmed quote.

## CSP / WebAssembly regression

- Moves route-specific Content Security Policy handling out of overlapping static header matchers and into the request proxy.
- `/lab` and its subpaths receive the narrow `wasm-unsafe-eval` capability required by the Lab WebAssembly runtime.
- Non-Lab pages receive the normal policy and no longer inherit the Lab WebAssembly exception.
- Production JavaScript `unsafe-eval` remains disabled.
