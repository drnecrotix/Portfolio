# v1.1.97 - Type-aware Gallery work details

## Gallery admin

- Keeps the compact list-first Gallery workspace.
- Uses Creative Type as the single public Gallery taxonomy.
- Keeps only the focused Creative Types: Photography, Traditional Art, Digital Art, Video and Other.
- Removes the duplicate Photoshoot Creative Type; existing Photoshoot entries migrate to Photography at normalization time.
- Existing Drawing and Mixed Media entries migrate to Traditional Art, while existing Painting entries are presented as Traditional Art.
- Media kind is derived automatically from Creative Type, so editors no longer choose both Media type and Creative type.
- Keeps Works, Published, Page and Interface separated into compact tabs.

## Type-aware Work details

Work details adapt to the selected Creative Type and only relevant metadata is presented in Admin and on the public work page.

- Photography: photographer, model/subject, location/date, device type, camera, lens, film stock, sensor/format, focal length, aperture, shutter speed, ISO and lighting.
- Traditional Art: artist, date, medium, materials, technique, surface/support and dimensions, covering drawing, sketching, painting and related physical artwork.
- Digital Art: artist, date, software, device/tablet, technique, canvas dimensions and output resolution.
- Video: video/direction, cinematography, editing, audio/sound, music, text/script, color grading and motion graphics credits, plus location/date, duration, resolution, frame rate and production software.
- Other: compact generic creative metadata fallback.

Empty Work details stay hidden at field level. Previously entered metadata is preserved if Creative Type changes, while irrelevant fields are not displayed.

## Public work details presentation

- Refines the Work details card into a compact metadata panel.
- Uses cleaner sans-serif typography for metadata labels and values.
- Keeps labels and values on a consistent baseline with stable column proportions.
- Improves spacing and wrapping for both narrow and desktop layouts.

## Gallery viewer mobile polish

- Hides the desktop zoom-help sentence on mobile so it cannot overlap the watermark.
- Gives the watermark its own bottom-right safe area with smaller mobile typography and spacing.
- Compacts the mobile zoom controls and hides the percentage reset label on small screens.
- Keeps the full zoom hint and percentage control available on larger screens.

## Gallery taxonomy cleanup

- Removes Gallery categories from the active settings model, Admin form, save flow, filtering and public presentation.
- Removes the old `galleryCategoryLabel` setting completely.
- Creative Type is now the only active taxonomy for Gallery works.
- Legacy per-item `category` values are read only as migration hints when loading older stored Gallery JSON and are not written back into the new model.

## Blog featured-image watermark

- Keeps the shared NecrotixLab watermark preset introduced in v1.1.96.
- Blog article pages apply the watermark only to the featured/header image instead of every image inside the article body.
- The Blog featured-image watermark is always anchored in the bottom-right corner for consistent presentation across publications.
- Original Media Library files and social/OG image URLs remain unchanged.

## Blog publishing

- New Blog posts default to Published in the editor while existing post statuses remain unchanged.

## Compatibility

- Existing Photoshoot items are treated as Photography without losing media or descriptive content.
- Existing Drawing, Painting and Mixed Media items remain compatible and normalize into Traditional Art without losing their metadata.
- No Prisma migration is required for the Gallery metadata expansion because Gallery settings remain JSON-backed.
- No dependency changes.
- Homepage slider, Articles visual layout and Projects visual layout are not redesigned by this release.
