# v1.1.90 - Wiki navigation shortcuts

## Navbar Wiki shortcut

- Replaces the old globe/language shortcut in the global navbar with a dedicated Wiki index shortcut.
- Uses the `LibraryBig` icon to communicate knowledge/reference content more clearly than the previous globe icon.
- Links directly to `/wiki/articles` on desktop and mobile.
- Adds active Wiki coloring while browsing Wiki article routes.
- Removes the obsolete locale-toggle state and full-page reload logic from the Navbar.

## Wiki article index

- Adds a direct `Career Dossier` shortcut from `/wiki/articles` to `/resume`.
- Uses a briefcase icon to distinguish the professional profile from Wiki content.
- Changes the compact mobile shortcut layout to a 2 × 2 grid so Main article, Articles, FAQ and Career Dossier remain readable on narrow screens.

## Release

- Version: `1.1.90`.
- No Prisma migration.
- No dependency changes.
- Career Dossier PDF management introduced in v1.1.89 remains unchanged.
