# Portfolio v1.2.20

## Store visual refresh

- Redesigns the public `/store` landing area into a more editorial, premium marketplace experience without adding popups, countdowns or aggressive sales UI.
- Adds a dynamic featured/latest product showcase inside the Store hero using the product cover image when available.
- Adds subtle visual depth with restrained grid/radial backgrounds, clearer typography hierarchy and small catalog summary blocks.
- Keeps the existing clean Necrotix Lab aesthetic and protected digital-delivery messaging.

## Catalog improvements

- Adds a clearer `Browse the collection` section with result count.
- Adds product counts to category filters.
- Refines search and sorting controls into a quieter compact toolbar.
- Gives product cards a more finished surface treatment while keeping image-first browsing.
- Allows the first featured product to use a wider editorial card when the filtered catalog contains at least three products.
- Preserves responsive desktop/mobile behavior and horizontal overflow protections.

## Compatibility

- No Prisma migration is required.
- No changes to checkout, cart, payment-provider, download-grant or Store storage behavior.
- Existing Store products require no data changes.
