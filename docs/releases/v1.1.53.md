# Portfolio v1.1.53

## Project editor and presentation fixes

This update packages the fixes added after v1.1.52.

### Projects
- Makes project content block markers such as `[[features]]`, `[[mission]]`, `[[chronicles]]` and `[[installation]]` render reliably when inserted through the rich editor.
- Removes the duplicate top Preview action from the project edit screen and keeps the unsaved-changes Preview in the sticky save bar.
- Adds an optional Download URL field next to Repository URL and Demo URL.
- Shows a Download button in Project Access only when a Download URL is configured.
- Shows the global header/navigation on project detail pages, matching the Blog article experience.

### Editor
- Gives Quote blocks a clearer WordPress-style appearance in the rich editor and project article rendering.

### Loader
- Replaces the first-visit `Hello` loader with `Niko` while leaving route-level preload behavior separate.

### Upgrade notes
- No Prisma migration is required.
- Existing projects remain compatible; Download URL is optional.
