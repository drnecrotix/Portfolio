# v1.1.76

## Compact Journey admin editor

- Reworks Education, Journey and Experience management into compact list-first rows inspired by the Blog admin list.
- Shows the record title, organization, type and useful date/location metadata before editing.
- Opens only the selected record form through an Edit control, dramatically reducing page length and scrolling.
- Adds search to Education, Journey and Experience datasets.
- Keeps Add and Remove controls while automatically opening newly created records for editing.
- Makes Categories and Highlight settings collapsible to keep the workspace compact.

## Stable admin tabs

- Keeps the General, Education, Journey, Experience and Partners & Sponsors tabs.
- Removes Framer Motion tab indicator and tab-panel transition effects that could intermittently glitch during tab changes.
- Keeps AJAX save feedback, save-button animation, toast notifications and local draft protection.

## Journey page identity

- Changes the canonical public route from `/experience` to `/journey`.
- Keeps `/experience` as a permanent redirect to preserve existing links.
- Adds an editable Page name setting in General while keeping the public slug fixed to `/journey`.
- Uses the configured Page name in the Journey admin heading and matching public/admin navigation labels.
- Updates navigation fallback, footer defaults and sitemap to use `/journey`.

## Release / updater

- Version: `1.1.76`.
- No Prisma schema migration.
- No dependency changes.
- Compatible with the existing Admin updater and N0C deployment flow.
