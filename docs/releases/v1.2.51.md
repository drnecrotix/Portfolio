## Digital Footprint — more platforms, named profile links, Hudson Rock

- **Social profile probes**: X, Instagram, Facebook, Threads, LinkedIn, TikTok, Twitch, Pinterest, Medium, Telegram, Linktree, Steam, Spotify, SoundCloud, Badoo, Snapchat, About.me, Behance, Duolingo

### Limits
- Facebook / Instagram / Tinder / Zoom / Microsoft often block anonymous probes or lack public username profiles
- Soft URL matches can false-positive — always confirm ownership
- Public breach APIs do not return dump rows or plaintext passwords
