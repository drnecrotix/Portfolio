# v1.2.11

Improves the Admin Dashboard traffic presentation and makes the GitHub updater easier to understand while it deploys a release.

## Dashboard traffic

- Moves Traffic overview directly below the Dashboard header so traffic is visible immediately when the admin area opens.
- Keeps the weekday chart for the 7-day and 30-day ranges.
- Replaces ambiguous `Views` / `Visits` wording with `Pages opened` and `Visitor sessions`.
- Adds short explanations to the traffic summary cards.
- Makes the weekday chart more explicit with selected-day averages, busiest weekday and pages-per-session context.
- Refreshes Dashboard traffic every 5 seconds.
- Gives `Live now` a subtle green state when visitors are active and a subtle red state when nobody is active, with a smooth pulse/transition.
- Clarifies country and device labels.
- Expands recognised country headers for common CDN/hosting proxy setups without storing raw IP addresses.

## GitHub updater

- Removes the long updater description from the Dashboard card.
- Adds installed and available version indicators.
- Adds a visible deployment pipeline: Download, Sync files, Dependencies, Database, Build and Activate.
- Adds a deployment progress bar and current-stage highlighting.
- Polls update status more frequently while a deployment is running.
- Infers progress from the existing update-worker status messages, keeping compatibility with current N0C update workers.

## Release

- Version `1.2.11`.
- No Prisma migration.
- No new dependencies.
