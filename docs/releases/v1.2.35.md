# Portfolio v1.2.35

## Navigation dropdown variants

- Rebuilds the desktop dropdown engine around the existing Radix Popover dependency for portal rendering, viewport collision handling, outside-click dismissal and reliable overlay positioning.
- Replaces the previous dropdown presentation with three distinct selectable layouts while keeping the existing stored style values compatible:
  - `Compact` is presented as **Minimal** - a narrow, low-noise popover list.
  - `Standard` is presented as **Glass** - a balanced NecrotixLab glass panel with richer link rows.
  - `Mega` is presented as **Mega cards** - a wider two-column card layout for larger groups.
- Keeps `Auto`, which selects Minimal, Glass or Mega cards from the number of visible submenu links.
- Uses the existing `dropdownStyle` database field, so no Prisma migration is required.

## Navigation behavior

- Keeps hover and click activation while improving viewport-aware placement near screen edges.
- Adds Arrow Up / Arrow Down menu traversal plus Home and End navigation.
- Preserves Escape dismissal and outside-click closing through the popover primitive.
- Keeps internal/external link treatment, active-route indication and theme-aware styling.
- Uses contained scrolling for long dropdowns and prevents the site smooth-scroll layer from hijacking the menu list.

## Admin navigation editor

- Replaces the old dropdown-style wording with **Auto / Minimal / Glass / Mega cards**.
- Adds a visual variant selector with small layout previews when editing a dropdown item.
- Shows the selected dropdown variant directly on the navigation item row.
- Keeps the compact selector in the new-item form for fast menu creation.

## Compatibility

- No Prisma migration.
- No navigation schema changes.
- Existing `auto`, `compact`, `standard` and `mega` values remain valid.
- Mobile fullscreen navigation keeps its existing behavior; this release targets the desktop dropdown presentation.
