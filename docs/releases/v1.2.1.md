# v1.2.1

Gallery editing resilience, media picker scrolling, balanced Grid layout and updater stability.

## Gallery save protection

- Makes Gallery saves tab-scoped instead of allowing one form submission to rewrite every Gallery section.
- `Works` can update Gallery works only.
- `Page` can update public Gallery page text only.
- `Interface` can update Gallery labels and controls only.
- `Published` cannot overwrite Works, Page or Interface data.
- Missing submitted fields always preserve their current database values.
- Creates an automatic Gallery snapshot before every Works save and retains the 10 newest Gallery snapshots for recovery.

## Gallery tags

- Replaces the comma-normalized text field with the shared chip-style TagInput.
- Comma and Enter commit a tag immediately.
- Leading `#` is normalized away for storage and displayed consistently in Gallery.
- Prevents duplicate tags, supports Backspace removal when the draft is empty and provides individual remove buttons.
- Keeps Gallery work search and public tag routes synchronized with the saved tag array.

## NSFW editor control

- Replaces the verbose checkbox row inside the work editor with a compact switch control.
- Shows clear `ON` / `OFF` state while preserving the existing NSFW blur and View full work behavior.

## Media Picker

- Marks the Media Library result list as a Lenis-safe nested scroll region.
- Stops wheel propagation to the page smooth-scroll controller.
- Adds overscroll containment so mouse-wheel scrolling remains inside the media list.
- Applies the fix globally to MediaPicker usage across the Admin panel.

## Gallery Grid

- Removes the narrow `tall` card variant that could create awkward vertical strips on desktop.
- Uses `standard`, `wide` and `feature` editorial sizes instead.
- Uses five columns on normal large desktop widths and expands to six columns only on very wide displays.
- Keeps dense editorial packing, existing overlays, NSFW previews and lightbox behavior.

## Legacy cleanup

- Removes the obsolete `getAllGalleryImages` filesystem loader after CMS Gallery became the single source of truth.
- Removes the final no-op `NavigationShortcuts` component and its empty mount while retaining the surrounding Expertise background section.

## Updater resilience

- Moves read-only `Check update` requests to the stable `/api/admin/update-check` endpoint instead of invoking a browser-held Server Action reference.
- Avoids stale Server Action IDs after a deployment, which could make an already-open Admin tab fail until the page was refreshed.
- Retries one transient error response as well as network/transport failures.
- Keeps update responses uncached.

## Release

- Version `1.2.1`.
- No Prisma migration.
- No new dependencies.
