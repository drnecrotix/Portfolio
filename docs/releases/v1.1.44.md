# Portfolio v1.1.44

## Gallery lightbox and Media Library hardening

This maintenance update packages the fixes merged after v1.1.43 so they are discoverable through the Admin Dashboard updater.

### Gallery
- Replaces the old in-section gallery overlay with an isolated fullscreen lightbox rendered through a React portal into `document.body`.
- Prevents the global header, footer and floating navigation from appearing above opened gallery media.
- Locks background scrolling while the lightbox is open and restores the previous page position when it closes.
- Adds Escape-to-close and keyboard previous/next navigation.
- Keeps image and video presentation isolated from Gallery page stacking contexts.

### Media Library
- Restricts uploads to supported image formats, video formats and ZIP archives.
- Applies the restriction in the Media Library UI, Media Picker, bulk upload server action and `/api/media` endpoint.
- Removes document/text/archive formats other than ZIP from new uploads.
- Keeps the maximum upload size at 10 MB per file.

### Upgrade notes
- No Prisma schema migration is required.
- Existing media records are not deleted or modified by this update.
- The version bump to `1.1.44` is required so the existing Admin Dashboard updater can detect this release after it reaches `main`.
