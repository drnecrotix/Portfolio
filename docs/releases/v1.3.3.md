# v1.3.3

## Native SEO Intelligence

- Replaces the mandatory DataForSEO-backed SEO Intelligence flow with a native NecrotixLab analysis engine.
- Requires no SEO API account, key, prepaid credits or subscription.
- Adds a bounded SEO Audit score covering technical health, on-page signals, content, internal links, indexability and structured data.
- Adds content-derived Keyword Intelligence with page coverage and cross-page intent/cannibalization flags.
- Replaces third-party organic competitor discovery with explicit user-supplied competitor comparison based on directly inspected homepage signals.
- Replaces global backlink metrics with Link Intelligence for directly observed internal links, outbound links, generic anchor text, nofollow usage and a bounded broken-target sample.
- Reuses the existing SSRF-protected public-page request layer and keeps concurrency/rate limits to protect server resources.

## Data integrity

- Does not fabricate Google search volume, CPC, live ranking positions, traffic estimates or global backlink counts when no authoritative market-data source exists.
- Clearly labels native metrics and the bounded crawl scope in the public UI.

## Provider cleanup

- Removes the DataForSEO card from Admin > API Integrations.
- Removes DataForSEO runtime code and environment placeholders from the active application.
- Existing historical release notes remain unchanged as a record of earlier releases.
