# Portfolio v1.2.52

## Digital Footprint: more platforms, breach sources, named profile links

- Adds **Hudson Rock** info-stealer breach signal for email lookups (device metadata only — passwords are never shown).
- Expands public profile coverage with JSON APIs (Duolingo, Chess.com, and existing developer platforms).
- Adds soft public URL probes for social platforms including **X, Instagram, Facebook, Threads, LinkedIn, TikTok, Twitch, Pinterest, Medium, Telegram, Linktree, Steam, Spotify, SoundCloud, Badoo** and more.
- Related accounts now prefer a **display name** when available and link the name to the public profile URL.
- Email lookups continue to probe username candidates (local-part + discovered handles).

### Limits
- Facebook / Instagram / Tinder / Zoom / Microsoft often block anonymous probes or have no public username profile; matches are soft signals and may false-positive.
- Public breach APIs still do not return full dump rows or plaintext passwords.
