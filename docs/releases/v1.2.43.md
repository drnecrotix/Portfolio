# Portfolio v1.2.43

## The Lab WebAssembly CSP fix

- Restores Spline/WebAssembly execution on `/lab` without re-enabling broad production `unsafe-eval` for the rest of the site.
- Adds the narrower CSP3 `wasm-unsafe-eval` capability only to `/lab` and its subpaths.
- Keeps the stricter production CSP from v1.2.42 everywhere else.
- Extends the public-route visual smoke suite so `/lab` must explicitly receive the WebAssembly CSP capability and unrelated routes must not inherit it.

## Local uploads hardening

- Prevents public directory listings for local Media Library storage under `/uploads` while keeping direct URLs for published media functional.
- Adds Apache rewrite/autoindex protections and `X-Robots-Tag` / `X-Content-Type-Options` headers for local uploads.
- Writes neutral `index.html` guards into local upload directories as a fallback when a hosting layer does not honor every `.htaccess` directive.
- Re-applies the protection automatically on production startup so existing N0C/Passenger upload directories are hardened after the update and restart.
- Applies the same protection when new local Media Library files are written.
- Marks `media-storage` as `server-only` and extends the Client Component boundary audit so browser code cannot import the storage runtime.

## Notes

- Public images still require a directly retrievable media URL in the browser. This release hides directory enumeration and discourages search indexing; it does not attempt to make already-public media bytes private.
- Cloudflare R2 public media behavior is unchanged.
- No Prisma migration or content schema change is included.
