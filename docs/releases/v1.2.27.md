# Portfolio v1.2.27

## Blog archive refinements

- Restores the existing animated `FlowingMenu` as the primary `/blog` publication list.
- Removes the new Latest publication spotlight/slide that did not match the established Blog visual identity.
- Replaces publication-type tabs with `All Publications` plus real publication tags and tag counts.
- Keeps search, category filtering, latest/oldest sorting, clear filters and nine-item pagination.
- Keeps the lightweight archive payload introduced in v1.2.26 so full article HTML is not sent just to render the Blog archive.
- The `BlogArchiveClient` change is an intentional protected-design adjustment and is covered by the PR `design-approved` review label.

## Publication fixes

- Keeps the new v1.2.26 publication reading design, reading time, progress, TOC, heading anchors, code-copy controls, image preview, related content, likes, views, language switching and comments.
- Makes `Back to journal` a deterministic link to `/blog` instead of browser-history navigation.
- Makes quote styling non-destructive so the renderer no longer forces a new size, italic style or text alignment over formatting authored in the editor.

## Compatibility

- No Prisma migration.
- No Post schema changes.
- Existing publications, tags, categories, translations and Tiptap content remain compatible.
