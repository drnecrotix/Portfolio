# Portfolio v1.2.44

## Protected public creative media delivery

- Replaces managed Media Library URLs in published Blog featured and inline images with opaque `/api/blog-media/{id}` URLs.
- Generates a flattened WebP derivative on the server with the configured NecrotixLab watermark embedded into the pixels.
- Keeps original managed media URLs out of Blog article markup, translated content responses, related-publication previews and social metadata.
- Serves protected derivatives with private no-store, noindex and nosniff response headers.
- Validates that an opaque media ID belongs to an image referenced by a currently published Blog post before returning any bytes.
- Keeps Media Library and administration previews unchanged.
- Extends the same pixel-level derivative protection to managed Gallery images, thumbnails, series images and social metadata.
- Extends protected delivery to managed Project covers and gallery images.
- Leaves Homepage, Wiki, Journey and Media Library/Admin media unchanged and unwatermarked.

## Reliability verification

- Includes clean-load and reload checks for `/lab`, `/admin` and the protected Blog media route.
- Keeps Passenger cold starts bounded by removing the synchronous recursive walk of the complete local uploads tree; root rules remain inherited and new upload directories keep their fallback guards.
- No Prisma migration or content schema change is required.

## Boundary

- Browsers must still receive the protected derivative to display it, so that watermarked derivative can be saved or captured.
- The original managed URL and original image bytes are no longer included in the public Blog response.
