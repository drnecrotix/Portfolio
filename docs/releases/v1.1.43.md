# Portfolio v1.1.43

Release date: 2026-08-22

## Highlights

### SEO and discovery
- Added Blog and Project social preview image fallbacks.
- Consolidated social preview, crawler, sitemap and RSS controls in the SEO admin area.
- Added configurable sitemap and RSS behavior.
- Added RSS discovery metadata and robots integration.
- Added hourly sitemap/RSS cache behavior with content-triggered revalidation.

### Cache and update behavior
- Added long-lived caching for hashed Next.js static assets and browser/CDN caching for regular public assets.
- Expanded the Admin Dashboard public cache revalidation control.
- Blog and Project mutations now refresh discovery routes automatically.

### Blog and Project editing
- Removed the duplicate Blog preview flow and fixed preview overlay stacking.
- Added local recovery drafts for Blog and Project editors.
- Added unsaved-change protection for accidental refresh/tab close.
- Added restore/discard controls and local cache enable/disable behavior.

### Gallery
- Fixed Gallery lightbox background scrolling and header/footer stacking.
- Added social video URL support for YouTube, Vimeo, TikTok, Instagram, Facebook, X/Twitter, Pinterest and Dailymotion.
- Added Pinterest media URL recognition.
- Added automatic social thumbnail discovery using provider/oEmbed metadata with Open Graph/Twitter metadata fallback.
- Custom thumbnail selection is used as a fallback when automatic discovery is unavailable.
- Added remote image host support for common social thumbnail CDNs.

## Admin updater

This release bumps the application version from `1.1.42` to `1.1.43`. Once this release PR is merged into `main`, installations running `1.1.42` can detect `1.1.43` through the Admin Dashboard GitHub updater and install it using the existing self-update workflow.

## Notes
- No Prisma schema migration is introduced by this release.
- Existing site settings remain backward compatible; new SEO/RSS settings are stored in the existing JSON settings structure.
