# Portfolio v1.2.54

## Digital Footprint — Floe-style improvements

1. **Richer exposed data** — HIBP, LeakCheck Public, XposedOrNot and EmailRep now populate structured `exposedData` cards (breach date, domain, record counts, reputation flags, field types).
2. **Optional Pro providers**
   - LeakCheck Pro (`LEAKCHECK_API_KEY`) — structured records; passwords redacted
   - DeHashed (`DEHASHED_EMAIL` + `DEHASHED_API_KEY`) — identity records; secrets redacted
3. **Public web dorking** — reviewed Google / DuckDuckGo / Yandex / Bing recipes per query type.
4. **Stronger identity graph** — broader username extraction from findings, second-pass profile enrichment, no false related accounts from email local-part.
