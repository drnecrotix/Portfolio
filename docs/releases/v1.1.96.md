# v1.1.96 - Global Blog + Projects Watermark

## Shared watermark

- Adds one global watermark preset shared by Blog article images and Project images.
- No per-post or per-project watermark fields are added.
- Default watermark is `© NecrotixLab`, matching the subtle Gallery viewer treatment.
- The overlay is non-destructive and never modifies Media Library originals.

## Public coverage

The shared watermark is applied to images rendered inside:

- Blog article featured images.
- Images embedded in Blog rich-text content, including images loaded after locale switching.
- Project hero images.
- Project gallery images.
- Project lightbox images.
- Images embedded in Project rich-text content.

A scoped MutationObserver handles images that appear dynamically without changing the stored HTML.

## Admin

- Adds `Appearance -> Watermark` at `/admin/watermark`.
- Supports enable/disable, watermark text, opacity, position and small/medium size.
- Includes an inline preview and save-without-navigation workflow.
- Settings are stored in the internal `__content-watermark-config` Page record, so no Prisma migration is required.

## Isolation

- Gallery keeps its own per-work copyright watermark behavior.
- Original uploaded files remain untouched.
- Downloaded files remain untouched.
- OpenGraph and Twitter/social preview source images remain untouched.
- Blog and Project editors do not expose individual watermark controls.
