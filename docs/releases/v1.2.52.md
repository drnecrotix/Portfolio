# Portfolio v1.2.52

## Fix: email search no longer probes accounts by nickname

- Email lookups no longer treat the email local-part as a username for public/social profile sweeps
- Account discovery for email uses email-capable providers only (HIBP, LeakCheck, XposedOrNot, Hudson Rock, Holehe, Gravatar, GitHub email search, GitLab public email, domain posture)
- Username probes (GitHub API profiles, Instagram URL checks, etc.) run only as a **second pass** when a real handle was discovered from an email-linked account (e.g. GitHub `@login` from `email in:email` search)
- Holehe findings now include structured `exposedData` with matched email and service name
