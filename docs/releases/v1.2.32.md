# Portfolio v1.2.32

## Traffic activity consistency

- Repairs a gap where a visitor could appear in `Live now` without a matching `Recent page activity` record when the first successfully received analytics request was a heartbeat.
- Allows heartbeats to self-heal retained activity only when they represent a new visit, a changed page path, or a current session/path that has no retained page event yet.
- Keeps steady-state heartbeats lightweight and avoids adding repeated page-history rows for the same open page.
- Counts a recovered navigation as a page view so retained history and aggregate page-view totals stay aligned.

## Current page indicators

- Correlates retained page activity with the active traffic session instead of relying only on IP matching.
- Marks the currently open page for an active session with a `LIVE` badge in `Recent page activity`.
- Adds a subtle live-row highlight and emphasizes the short-lived IP value on the current row.
- Uses session + current path matching so shared/NAT IP addresses do not incorrectly mark unrelated visitor rows as current.
- Removes the `LIVE` marker automatically when the session leaves the existing live-visitor window.

## Compatibility

- No Prisma migration.
- No changes to the traffic retention windows.
- Existing traffic metrics and retained page activity remain compatible.
