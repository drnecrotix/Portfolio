# Portfolio v1.1.52

## Homepage readability and Journal animation

This update improves the readability of the full-screen Blog and Projects sections while preserving the landing-page scroll flow introduced in v1.1.51.

### Journal
- Keeps only the compact `Journal` section heading and item count.
- Removes the secondary homepage Blog title and subtitle from the section header.
- Enlarges featured-image previews, publication titles, metadata and excerpts for easier reading.
- Adds smooth staggered entrance animation for Journal list rows when the section comes into view.
- Keeps the list layout and `View all posts` action.

### Projects
- Keeps only the compact `Projects` section heading and item count.
- Removes the secondary homepage Projects title and subtitle from the section header.
- Enlarges project thumbnails, titles, descriptions, status badges, categories and tech-stack text.
- Preserves the `/projects`-inspired list design.

### Landing page behavior
- Keeps Hero, Journal and Projects as separate full-screen sections.
- Preserves smooth forward and reverse wheel navigation between sections.
- Hidden Journal or Projects sections continue to be skipped automatically.

### Upgrade notes
- No Prisma schema migration is required.
- Existing Homepage Admin visibility and item-count settings remain unchanged.
