# v1.1.79 - GitHub-backed Lab proof

## The Lab

- `Used in real work` now prefers live data from the authenticated GitHub profile instead of relying only on the local portfolio dataset.
- Public owned non-fork repositories are analyzed for:
  - GitHub languages
  - repository topics
  - `package.json`
  - `requirements.txt`
  - `pyproject.toml`
  - `composer.json`
  - Dockerfile presence
  - GitHub Actions workflow presence
- Technology usage is counted by unique repository, not by dependency occurrences.
- Each technology card links to recent repositories where it was detected.
- The UI clearly shows whether it is displaying `Live GitHub data`, synchronizing, or using `Portfolio fallback`.

## Reliability and privacy

- Only public repositories owned by the GitHub account are included.
- Forks are excluded.
- GitHub proof responses are cached for one hour with stale-while-revalidate support.
- The existing local portfolio project data remains the immediate and failure-safe fallback.
- The feature reuses the existing optional `GITHUB_TOKEN` configuration.

## Deployment

- No Prisma migration.
- No new dependencies.
- Compatible with the existing Admin updater and N0C WASM build flow.
