# Portfolio v1.2.16

## Digital Store local private storage

- Makes local private filesystem storage the default temporary backend for new Digital Store product files.
- Removes the requirement for a Cloudflare R2 private Store bucket before uploading downloadable products.
- Keeps Store files outside the public web directory and serves them only through the existing protected download grant route.
- Keeps optional R2 fallback compatibility for Store files that were already stored in R2.
- Adds optional `STORE_PRIVATE_STORAGE_PATH` for a persistent absolute server path.

## Admin updater

- Bumps the application version from `1.2.15` to `1.2.16` so the merged Store storage changes are detected by Admin > Portfolio Updates.
- The updater reads the version from `main/package.json`; code-only merges that keep the same version are intentionally not reported as a new update.

## Compatibility

- No Prisma migration is required for this release.
- Creem and Lemon Squeezy checkout behavior remains unchanged.
- Existing Store products and download grants remain compatible.
