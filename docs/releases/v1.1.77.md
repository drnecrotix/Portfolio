# v1.1.77

## Journey / Experience bulk manager

- Adds checkbox selection to Education, Journey, Experience and Partners & Sponsors lists.
- Adds bulk Show / Hide and Delete actions.
- Adds bulk Archive / Restore for Education, Journey and Experience.
- Adds bulk Move from Journey to Experience and from Experience to Journey.
- Keeps hidden and archived records in the CMS while excluding them from the public `/journey` page.
- Stores entry visibility/archive state separately from the existing Experience content JSON for backward compatibility.

## Drag-and-drop ordering

- Adds drag handles to Education, Journey, Experience and Partners & Sponsors rows.
- Saves the reordered arrays through the existing AJAX Journey save flow.
- Journey timeline now respects the CMS order instead of re-sorting every record by date.
- Dragging is temporarily disabled while a search filter is active to avoid ambiguous filtered ordering.

## Journey and Experience media

- Replaces the plain logo path field with the shared Media Library picker for Journey and Experience records.
- Supports Media Library selection, upload, clearing and inline preview.
- Compact list rows also show the selected image/logo preview.

## Gallery loading

- Removes the deferred mount around the Gallery grid so media can start loading immediately after the page mounts.
- Keeps the existing `loading="lazy"` behavior on Gallery images so off-screen media remains deferred by the browser.
- Heavy GLSL background rendering remains deferred separately.

## Release / updater

- Version: `1.1.77`.
- No Prisma schema migration.
- No dependency changes.
- Compatible with the existing Admin updater and N0C deployment flow.
