# Portfolio v1.2.45

## Selectable content watermark rendering

- Adds `CSS only` and `Pixel + CSS fallback` rendering modes to Content Watermark.
- Uses the configured watermark text, position, size and opacity for protected Blog, Gallery and Project derivatives.
- Hides the CSS overlay when the protected image already contains the pixel watermark, preventing duplicate watermarks.
- Keeps the CSS overlay active as a fallback for applicable images without an embedded watermark.
- Leaves original Media Library files, OpenGraph/social images, Homepage, Wiki, Journey and Admin media unchanged.

## Verification

- Content Watermark settings remain backward-compatible and default to pixel mode for existing saved configurations.
- TypeScript, targeted ESLint, client boundary and client bundle audits pass.
- The N0C production build completes successfully.
