# Portfolio v1.1.85

## Wiki navigation visibility fix

- Fixes manually configured `/wiki` navigation items being hidden from the public navbar even when `Visible` is enabled.
- Removes the v1.1.82 legacy heuristic that suppressed any item matching `Wiki` + `/wiki` + sort order `25`.
- Public navigation now honors the CMS navigation record instead of guessing whether a Wiki item is legacy or manually managed.
- Wiki remains fully manual: the release does not auto-insert `/wiki` into the public navigation or choose its position.
- The existing Navigation manager remains the single source of truth for Wiki label, visibility, hierarchy and order.

## Mobile navigation

- Verified that the mobile navbar does not impose a fixed item limit and renders every item returned by `/api/navigation`.
- No mobile design changes are required; fixing the API restores Wiki on desktop and mobile consistently.

## Release

- Version `1.1.85`.
- No Prisma migration.
- No dependency changes.
- Existing v1.1.84 stale-file-safe updater path is preserved.
