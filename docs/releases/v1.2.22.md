# Portfolio v1.2.22

## Live traffic analytics

- Adds a lightweight 60-second visitor heartbeat so the live visitor count stays accurate while someone remains on the same page.
- Tracks the current public pathname inside the short-lived traffic session record.
- Shows which public pages are being viewed right now and how many active visitors are on each page.
- Uses a 30-minute inactivity boundary for new visits so period totals behave more like conventional web analytics sessions.
- Heartbeats refresh live activity without incrementing page-view totals every minute.
- Adds optional live city context only when the hosting/CDN already supplies a city header.
- Does not perform an external IP-to-city lookup and does not collect precise coordinates.

## Clearer and more compact traffic overview

- Replaces ambiguous `Page opens`, `Session depth`, `Share of traffic` and `Country coverage` summary cards with visitor-focused information.
- Shows visitors online now, active pages, total visits for the selected period and countries that generated visits.
- Places `Pages being viewed` and `Daily visits` side by side on wide screens to reduce wasted vertical space.
- Makes live-page and location lists independently scrollable so large traffic volumes cannot stretch or break dashboard blocks.
- Removes the duplicate `Visitors online by country` block.
- Adds a single `Audience locations` panel with `Countries` and `Cities` tabs.
- `Countries` shows exact period visits plus live visitors; `Cities` is intentionally live-only and appears only when infrastructure supplies the city label.
- Keeps the world map as a secondary visualization and now shades it by visits rather than raw page opens.
- Makes the map more compact and keeps exact location numbers in the adjacent list.
- Simplifies device analytics to visit counts with compact relative bars.

## Gallery tag navigation

- Fixes encoded Gallery tags such as `black&white` so `/gallery/tag/<tag>` resolves the same normalized tag stored on Gallery works.
- Normalizes tag matching consistently for URL-encoded values, case and whitespace.
- Adds a visible `Clear filter` control on tag-filtered Gallery pages that returns to `/gallery` and restores all works.

## Admin navigation

- Makes the expanded desktop admin sidebar independently wheel-scrollable when its content is taller than the viewport.
- Uses a viewport-bound sidebar and compact group spacing so expanded sections remain accessible without scrolling the whole admin page.

## Privacy and retention

- Updates the Privacy & GDPR and Cookie policies for live pathname reporting, optional infrastructure-provided city labels and the 30-minute visit inactivity window.
- City labels stay only in short-lived traffic-session rows and are not copied into longer-lived country/device aggregates.
- Raw IP fallback continues to be used only for country resolution and remains short-lived.

## Database

- Adds nullable `TrafficSession.currentPath` for short-lived live-page reporting.
- Adds nullable `TrafficSession.currentCity` for optional short-lived city context supplied by the hosting/CDN.
- Adds an index on `currentPath` and `lastSeenAt` for efficient live-page queries.
- Existing aggregate traffic metrics remain compatible and no historical traffic data needs to be rewritten.
