# Portfolio v1.2.31

## Reading progress accuracy

- Recalculates Blog reading progress against the actual article viewport instead of approximate absolute-page offsets.
- Uses fixed reading lines so progress starts when the article body reaches the reading position and reaches 100% when the final article content reaches the lower reading position.
- Adds `ResizeObserver` support so late-loading images and dynamic article height changes do not leave the percentage stale.
- Keeps the bottom floating progress rail hidden before the article body and after the reader has moved past the post.

## Admin nested scrolling

- Disables Lenis handling inside the protected admin shell so nested CMS lists use native browser scrolling.
- Removes the manual React wheel handler that could scroll both the nested list and the document on the same wheel event.
- Lets the browser own nested `scrollTop` updates instead of manually applying wheel deltas from React handlers.
- Applies contained overscroll behavior to admin `overflow-y-auto`, `overflow-y-scroll` and `overflow-auto` regions, covering the desktop sidebar, mobile admin menu, Analytics lists, Media Picker, Wiki lists and similar bounded CMS panels.
- Keeps the compact admin scrollbar treatment for the sidebar and Analytics data lists.

## Traffic analytics

- Simplifies `Visits by device` to exactly two fields: broad device type and visit count.
- Removes recent IP addresses from the device summary UI and from the device-summary API payload.
- Keeps IP context only in `Recent page activity`, where it is attached to a specific retained page event and remains subject to the existing short retention window.
- Keeps the OS column in `Recent page activity`.
- Restores the live-status color semantics for `Visitors online`: red when there are zero active visitors and green when one or more visitors are online.

## Compatibility

- No Prisma migration.
- No Post schema changes.
- Existing traffic metrics and retained page activity remain compatible.
