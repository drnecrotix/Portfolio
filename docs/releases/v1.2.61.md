# Portfolio v1.2.61

## Context-aware service estimates

- Replaces the old WARN/FAIL counting formula with finding-specific complexity classes: `simple`, `moderate`, `complex` and `specialist`.
- Gives different remediation costs to different findings instead of treating a missing meta description like a CSP, TLS or mail-authentication change.
- Applies a higher multiplier to `FAIL` findings than `WARN` findings.
- Adds a bounded affected-item adjustment for findings such as broken links, missing page titles, image alternatives, form labels, unnamed controls and duplicate IDs.
- Adjusts web-service estimates for CMS/technology complexity and whether hosting/CMS access is already available.
- Applies a modest bundle adjustment when several findings can reasonably be fixed together.
- Keeps email-domain work independent from CMS modifiers.
- Explicitly excludes the customer's entered budget from the automated estimate.
- Recalculates the authoritative estimate server-side from validated request data instead of trusting the browser-side display.
- Final pricing still requires manual review and a final quote from Kreatrics Customer Service.

The Web Health Suite design and audit logic are unchanged by this release.
