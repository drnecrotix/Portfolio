# v1.2.13

Adds the first native Necrotix Lab Store release for downloadable digital products.

## Digital Store

- Adds a public `/store` catalog and `/store/[slug]` product pages.
- Keeps the Store separate from Articles, Projects and the homepage design.
- Supports title, slug, descriptions, category, tags, EUR pricing, sale comparison price, featured state, cover image, SEO metadata and download limits.
- Adds Product and Offer structured data for published product pages.
- Adds published Store products to the XML sitemap.

## Admin

- Adds a new `Commerce` navigation group.
- Adds `Admin > Digital Store` for product management.
- Adds `Admin > Orders` for verified orders and download usage.
- Supports direct private digital-file upload while creating or editing a product.
- Supports multiple files per product.
- Maps each published product to a Lemon Squeezy Variant ID.

## Payments

- Adds Lemon Squeezy checkout creation through the Necrotix Lab backend.
- Adds signed webhook handling for `order_created` and `order_refunded`.
- Validates Lemon Squeezy webhook signatures before any order or download access is created.
- Adds Lemon Squeezy API Key, Store ID and Webhook Secret to the encrypted Admin > API Integrations vault.

## Secure downloads

- Uses a dedicated private Cloudflare R2 bucket for paid product files instead of the public Media Library bucket.
- Never builds public Store file URLs from `R2_PUBLIC_BASE_URL`.
- Creates purchase-linked download grants only after a verified paid order.
- Enforces order status, revocation state, optional expiry and a per-purchase download limit.
- Does not unlock the return page until the signed payment webhook has been processed.
- Revokes download access after a refund webhook.

## Database

Adds migration:

`20260904134500_digital_store`

The migration adds Store products, private product-file metadata, orders, order items, checkout sessions and download grants.

## Configuration

- Keep the existing `R2_BUCKET` for public Media Library assets.
- Create a separate R2 bucket with no public R2.dev/custom domain and configure it as `R2_STORE_BUCKET` or `Private Store bucket` in Admin > API Integrations.
- Give the R2 API credentials object read/write access to both required buckets.
- Configure Lemon Squeezy in Admin > API Integrations or with `LEMON_SQUEEZY_API_KEY`, `LEMON_SQUEEZY_STORE_ID` and `LEMON_SQUEEZY_WEBHOOK_SECRET`.
- Configure the Lemon Squeezy webhook URL as `/api/store/webhook` and subscribe to `order_created` and `order_refunded`.
- Set the Lemon Squeezy Variant ID on each product before publishing.
