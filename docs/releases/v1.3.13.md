# v1.3.13

Simplifies the website configurator without reducing the available project and CMS choices.

## Changes

- Replaces the long form with a four-step wizard.
- Shows only the information needed for the current step.
- Moves design, content and add-ons into an optional Advanced options panel.
- Removes repeated CMS fields.
- Uses quick choices for common CMS platforms, website types and project sizes.
- Keeps less common CMS platforms available under More CMS options.
- Improves the existing website section with a clear URL field and compact CMS selection.
