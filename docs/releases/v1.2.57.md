# Portfolio v1.2.57

## Website Inspector Node.js 22 compatibility

- Fixes Website Inspector requests failing with `Invalid IP address: undefined` on Node.js 22 environments.
- Disables Node's automatic address-family selection for the inspector request so the custom SSRF-safe DNS lookup continues to return the single validated address shape expected by the request pipeline.
- Rejects empty or invalid DNS lookup results before they can reach the socket connection layer.
- Keeps the existing localhost, private, loopback, link-local and reserved-address protections in place.

This is a runtime compatibility patch for Website Inspector v1. No inspection data is persisted and the public request limits, redirect validation, timeout and HTML-size cap remain unchanged.
