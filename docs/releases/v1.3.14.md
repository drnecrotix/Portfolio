# v1.3.14

A clearer, guided website project configurator with contextual pricing and recommendations.

## Changes

- Replaces the overlapping purpose questions with a visual website type selector.
- Adds a page-count slider from a single Home page to 15+ pages.
- Shows the estimate only after the client makes a meaningful project choice.
- Presents recommended functions first and keeps the full add-on catalog available on demand.
- Adds contextual WordPress and WooCommerce plugin recommendations.
- Separates redesign and expansion projects from ongoing Website Support.
- Uses responsive icons and compact cards to make the choices easier to scan on mobile.
- Improves URL validation, form persistence, keyboard focus and step accessibility.
