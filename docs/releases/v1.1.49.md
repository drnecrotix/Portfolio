# Portfolio v1.1.49

## SEO Admin UX and social image cleanup

This update improves the SEO editing workflow in Admin and removes duplicated homepage-specific social image controls.

### SEO save feedback
- Shows a visible success toast after SEO settings are saved.
- Shows validation or save errors in the same notification system.
- Adds a loading state to the Save SEO settings button while the server action is running.
- Refreshes public metadata caches after a successful save.

### Media Library sync
- MediaPicker instances now synchronize through a shared browser event.
- Uploading a new image in one picker immediately adds it to the other open SEO media galleries.
- No manual page refresh is required before the new upload can be selected for Open Graph or Twitter/X.

### Simplified social preview images
- Keeps one Default social image as the general fallback.
- Keeps one optional site-wide Open Graph image override.
- Keeps one optional site-wide Twitter/X image override.
- Removes the duplicate Homepage Open Graph and Homepage Twitter/X override controls from SEO Admin.
- Clears legacy homepage-specific image overrides on the next SEO save so hidden old values cannot unexpectedly override the visible site-wide settings.
- Homepage now follows the same site-wide social image hierarchy automatically.

### Image priority
1. Blog or Project featured image, when the route has one.
2. Site-wide Open Graph or Twitter/X override, when configured.
3. Default social image.

### Upgrade notes
- No Prisma migration is required.
- Existing media files are unchanged.
- Version is bumped to `1.1.49` for Admin Dashboard update detection.
