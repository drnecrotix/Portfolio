# v1.2.4

Gallery interaction, console and route-loading polish.

## Gallery slider

- Replaces the React `onWheel` handler with a native `wheel` listener registered with `{ passive: false }`.
- Keeps mouse-wheel horizontal navigation while allowing `preventDefault()` to work correctly.
- Removes repeated `Unable to preventDefault inside passive event listener invocation` console errors.
- Preserves drag, swipe, buttons, scrubber navigation and the existing Gallery layout.

## Route loading

- Replaces the split-panel / slider-like route loader with a text-free generative signal constellation.
- Builds an abstract network of animated nodes and connecting paths instead of sliding the screen open from the sides.
- Adds a restrained radial grid, signal pulses and a short light-bloom dissolve when the destination page is ready.
- Keeps page names and slugs out of the loader.
- Preserves the separate first-visit homepage `Niko` animation unchanged.
- Keeps the existing preload context, Lenis scroll lock and reduced-motion behavior.

## Console notes

- Grammarly `Permissions policy violation: unload is not allowed in this document` messages are generated by the Grammarly browser extension, not by the Portfolio application.
- Chromium's `powerPreference option is currently ignored ... on Windows` message is a browser/WebGPU implementation notice and does not indicate an application failure.
- The iframe `allow` / `allowfullscreen` message is a non-breaking browser compatibility warning; fullscreen permission remains granted through the `allow` policy.
